# 실제 음표에 지정한 내성의 연결

사용자의 “순서대로 다 진행하세요.”에 따라, 외성 검사 다음 단계로 내성의 실제 연결을 대조합니다. 새 `musigen.inner_voices`는 **작성자가 지정한 음의 연결만** 검사하는 선택 명령입니다. 화음의 낮은 음 순서나 펼침화음 순서를 자동으로 성부라고 간주하지 않습니다.

```powershell
python -m musigen.inner_voices --piece <고정된 악보 폴더> --plan <내성 지정 JSON>
```

계획의 format은 `musicanote-inner-voices`, version은 1입니다. `score_sha256`은 `fingerprint(piece)`로 만든 실제 음표·화성·박자·빠르기의 지문입니다. `voices`마다 `id`, `label`, `events`를 둡니다. 각 음은 `bar`, `offset`(4분음표 단위), `hand: lh`, 실제 기보 `voice`, 철자·옥타브를 포함한 `pitch`로 지정합니다. 마지막을 제외한 음의 `next`에는 `kind`, `reason`을 넣습니다.

- `hold`: 같은 철자·옥타브 유지.
- `step_up` / `step_down`: 기보상 이웃음이며 1 또는 2반음 위/아래. 옥타브 바뀐 동일 음급을 순차 진행으로 인정하지 않습니다.
- `within`: 작성자가 `max_semitones`를 명시한 이동 한도.
- `max_gap`: 허용하는 쉼, 기본 0. 허용 범위 안이어도 끊어진 연결임을 보고합니다.
- 선택 `source_degree: 3` 또는 `7`: 실제 출발 화음의 해당 구성음인지 철자로 확인합니다. 종지·이끈음 기능을 자동 추정한 뜻은 아닙니다.

실제 음이 없거나 철자·시각·옥타브가 다르거나, 악보 지문이 바뀌거나, 같은 음을 서로 다른 성부로 중복 지정하면 거부합니다. 겹치는 음을 한 내성으로 지정하는 것도 거부합니다. 보고서는 지정한 연결 수와 전체 왼손 음 사건 중 지정한 수를 함께 표시합니다. 전체 성부 분리·대위법·양식 적합성 검사가 아닙니다. 쉼 한도와 도약 한도는 작성 의도이며 보편적인 음악 규칙이 아닙니다.

## 같은 두 시험곡의 수동 작성 수정

[3/4 A/B](http://127.0.0.1:8806/stage1/lyrical_34/index.html) / [4/4 A/B](http://127.0.0.1:8806/stage1/bright_44/index.html).

| 곡 | 변경 | 지정 연결 충족 | 범위 |
|---|---|---|---|
| 고요한 창가 | 8마디 A3→D4 | 2/3 → 3/3 | 왼손 음 사건 73개 중 6개 |
| 골목의 작은 걸음 | 12마디 `C3/q [G3,C4,Eb4]/h r/q`로 재배치 | 1/3 → 3/3 | A 90개, B 91개 중 각각 6개 |

3/4는 7마디 C♯4→8마디 D4, G3→F3을 같은 음역에서 연결했습니다. 4/4는 11마디 B3→12마디 C4, F4→E♭4를 잇되 베이스 C3 뒤 한 박을 기다려 화음을 칩니다. 이 쉼은 작성 계획에 허용했으며 연속 발음으로 표시하지 않습니다. 손 벌림을 무리하게 늘리는 해법은 사용하지 않았습니다.

이 수정은 새 감사 도구를 참고한 **작성자의 반주 수정**입니다. 자동 음 배치 최적화가 아닙니다. 3/4의 8마디와 4/4의 12마디만 바뀌었습니다. 기존 자료 선택·선율·화성·조성·박자·빠르기·표현은 같으며 공통 화성 XML도 같습니다. 페달은 없습니다. 두 수정 솔로의 자동 오류·경고는 0개, 3/4 공통 화성 악보의 기존 경고 1개는 유지합니다.

출력 `K:/MusicGeneration/motif-complete-flow/output/flow-v001/stage1`. 각 판의 `inner_voice_plan.json`, `inner_voices.json`, `inner_voices.html`에 실제 연결과 근거가 있습니다. 226개 테스트 통과, 새 솔로 PDF 2개 시각 검수. 청취 판단·전 성부 분석·기본 적용은 아닙니다. 다음 꾸러미에서 새 주제를 발전시킬 때 종지의 연결을 처음부터 계획합니다.
