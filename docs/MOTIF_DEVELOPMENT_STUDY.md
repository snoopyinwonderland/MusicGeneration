# 새 주제의 발전과 두 악보 — 오후의 편지

사용자의 “순서대로 다 진행하세요.”에 따른 2단계입니다. 새 자작 모티프를 작성하고 프레이즈·국소 조성의 검증된 참조를 읽어 **24마디, 3/4, F장조→D단조→F장조, 4분음표=78, 약 55초**의 곡을 만들었습니다. 주제와 설계는 작성자의 제안이며 사용자 선택이나 스타일 모델의 결과가 아닙니다.

[악보·피아노·XML/PDF](http://127.0.0.1:8806/afternoon-letter-v002/index.html) / [주제의 여정](http://127.0.0.1:8806/afternoon-letter-v002/development_story.html).

| 구간 | 역할 | 실제 확인 |
|---|---|---|
| 1–4 | 주제와 질문 | 1마디 원형, 2마디 같은 리듬, 딸림에서 쉼 |
| 5–8 | 응답과 첫 마침 | 5마디 원형 반복, F장조 종지와 내성 연결 |
| 9–12 | 단조에서 확대 | 원형의 음가를 두 배로 늘려 두 마디에 펼침 |
| 13–16 | 조각 반복과 고조 | 첫 두 음을 세 번 상행. 13마디 화성을 매 박 바꾸고 14마디 정점 뒤 D단조 종지 |
| 17–20 | 원형 재현 | F장조 귀환, 17마디 원형 보존, G7(V7/V)→C7 |
| 21–24 | 회상과 종결 | 첫 두 음을 길게 회상하고 으뜸화음에서 마침 |

첫 모티프의 음·리듬·쉼을 보존했습니다. 페달은 없습니다. 중간에는 반주를 쉬게 하고 마지막 여운은 기보한 음 길이로 만듭니다. 두 악보의 주선율은 같으며 화성 요약에는 26개 사건의 시점·길이·모든 구성음·베이스·전위·국소 조성·기능·종지 의도가 있습니다. 종지 의도는 독립적인 종지 판정과 구별합니다.

## 활용한 자료

- TAVERN의 B070 주제 첫 두 악구와 첫 변주 악구에서 기능 순서·끝의 쉼·발음 수 변화를 참고했습니다. 원곡 선율을 이어 붙이지 않았습니다. 원 자료는 6/8이며, 이번 3/4 곡의 화성과 변형은 작성자의 결정입니다. TAVERN, Devaney et al., CC-BY-SA-4.0.
- 원 XML과 주석 시각을 대조한 DCML 6악장 참조 스냅샷을 사용했습니다. Beethoven 01-2의 F장조→D단조, Mozart K279-2의 D단조→F장조, Beethoven 01-2의 V/V 관계를 이번 조성 설계와 대조했습니다. 공통화음은 8마디 F의 I/III, 16마디 Dm의 i/vi입니다. CC BY-NC-SA 4.0 선택 참조이며 자동 스타일 학습은 아닙니다.
- 기존 musicomp 자료를 1·2·3·5·6·11·17·18·21·22마디에 적용했습니다. 이 중 11마디는 이전 꾸러미의 선택적 음 배치 수정도 거쳤고, 자료가 없는 14마디 작성 패턴도 구성음을 보완했습니다. 종지·긴 주제 아래의 반주는 직접 작성했습니다.

## 실제 모티프 대조

새 선택 명령은 이미 생성한 곡의 작성 과정과 실제 악보를 확인합니다.

```powershell
python -m musigen.development_story --piece output/flow-v001/afternoon-letter-v002
```

recipe의 선택 필드 `motif_uses`는 `id`, `bar`, `label`, `kind`를 갖는 목록입니다. `kind: exact`는 음·철자·음가·쉼, `rhythm`은 음가·쉼, `transform`은 명시한 `ops`와 선택 `sequence: {times, step}`의 실제 결과를 비교합니다. offset은 4분음표 단위입니다. 같은 악보에서 설명만 ‘확대’로 바꾸거나, 원형의 쉼을 지우면 검증이 실패합니다.

작성 recipe·참조를 재컴파일한 설계와 저장된 설계·trace가 같아야 하며 실제 MusicXML도 고정 음표와 대조합니다. 결과는 `development_story.json/html`입니다. 자유 서술의 미학적 설득력이나 모든 모티프 사용을 자동 증명하는 기능이 아닙니다.

## 결과와 남은 판단

- 모티프 사용 주장 **7/7개** 실제 음표와 일치.
- 지정 내성 연결 **8/8개** 작성 의도 충족, 전체 왼손 음 사건 120개 중 지정 16개. 6개 연결은 계획한 한 박의 쉼을 포함하므로 연속 발음과 구별.
- 왼손 화음 구간의 3음·7음 생략 **0/26**, 명시 반주 요구 미충족 0마디.
- 피아노 솔로 자동 오류·경고 **0개**. 멜로디+화성 악보는 오류 0개, 병행5도 경고 **4개(1→2, 11→12, 13→14, 22→23)**. 요약 화음의 배치를 연주용 솔로와 혼동하지 않습니다.
- 전체 **231개 테스트 통과**. 두 PDF를 렌더링하여 표기·배치를 확인했습니다. 실제 주제 인식과 연결의 자연스러움은 사용자 청취가 남아 있습니다.

출력 `K:/MusicGeneration/motif-complete-flow/output/flow-v001/afternoon-letter-v002`. v001의 13마디 베이스와 마지막 반주를 작성 단계에서 다듬은 판입니다. 작품별 프로그램 규칙이나 계수를 추가하지 않았습니다. P3/P4 중단과 자동 스타일 생성 보류는 유지합니다. 다음 꾸러미에서 모티프 요청과 이 결과의 일치 여부를 검증하여 입력 화면에서 두 악보로 이어집니다.
