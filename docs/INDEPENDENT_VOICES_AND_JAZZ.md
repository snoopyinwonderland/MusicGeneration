# 양손의 독립과 재즈 색채 — 2026-11-11

사용자 의견은 첫 곡의 양손 contour가 비슷하며, 경과음·보조음의 연결을 다듬고 재즈 화성·리듬을 섞어 보자는 것이다. 「햇살에 남긴 문장」을 먼저 집중 수정했다. 나머지 네 곡은 앞선 호흡 수정본을 유지한다. [전후 듣기](http://127.0.0.1:8808/study-report.html), [다섯 곡 모음](http://127.0.0.1:8808/studies.html)에서 두 악보와 XML/PDF를 받는다.

최종 작성본은 `output/five-studies/sunlit_sentence/v007`, 감상 전달본은 원래 요청의 v003이다. 비교 기준은 작성 v005 / 전달 v002이며 이전 파일 해시를 확인했다. 첫 마디의 오른손 모티프·음가·쉼, F장조·4/4·기본 빠르기 92·24마디를 보존했다. 새 자동 작곡 모델의 출력이나 사용자 청취 승인으로 표시하지 않는다.

## 음악의 변경

| 구간 | 작성한 변화 |
|---|---|
| 1마디 | 오른손 A4–C5–D5의 상승에 왼손 윗성부 D4–C4–A3가 하강. F3 베이스를 유지하며 양손이 같은 윤곽을 따라가지 않게 함 |

| 17–20마디 | 주제 리듬 변형 재현, 긴 D5, B♭m6 위 D♭–C–D♭, 20마디 후반 양손 두 박 쉼 |
| 21–24마디 | 반음 접근과 Gm7–C7, G♭7을 거쳐 F6로 종결. 페달은 마지막 마디 한 곳 |

이번 왼손은 두 성부의 베이스와 화음으로 새로 썼다. 온마디 지속 베이스 아래에서 생기는 손 벌림도 새 발음뿐 아니라 동시에 유지되는 모든 음으로 확인했다. 최댓값은 11반음이다. 근음·3음·7음과 일부 6음을 유지하며 5음을 생략하는 셸 보이싱을 사용한다. 상세 화성 악보에는 전체 구성음을 남겨 실제 반주와 구별한다.

재즈 리듬은 악보에 쓴 엇박 진입·붙임줄·쉼이다. 자동 스윙 비율이나 루바토를 적용한 것은 아니다. 6음·장7화음·반감7화음·감7화음·차용화음·딸림 대리화음을 기존 코드 표기 범위 안에서 작성했으며, 생성 계수나 기본 화성 선택기를 바꾸지 않았다. 클래시컬 로마자 표시는 현재 국소 조성에 대한 기보 화음 분석이며 자동으로 모든 세컨더리 기능을 확정하는 해석은 아니다.

## 선택 관찰 함수

`musigen.voice_independence`는 악보를 고치지 않는 선택 호출 함수다.

- `contour(piece, lower='bass'|'top', lower_voice=None)`: 오른손 1성부의 최상음과 왼손 최저음/최상음의 움직임을 관찰한다. 왼손 성부 번호를 지정할 수도 있다. 같은 방향·반대 방향·한쪽 유지·양쪽 유지, 비교 사건 수, 함께 음을 유지한 시간을 보고한다. 쉼과 해제된 화음음을 새 하행 선율로 세지 않는다. 모든 같은 방향 움직임을 금지하거나 전곡 대위법을 인증하지 않는다.
- `embellishments(piece)`: 오른손 단선율의 인접 사건과 그 시점의 기보 화음을 대조한다. 같은 화성의 연속된 화음음–비화성음–화음음에서 경과음/보조음을 관찰하고, 다음 기보 화음음으로 반음 진행하는 접근도 구별한다. 앞뒤 쉼을 넘겨 보조음으로 분류하지 않는다. 화음의 명시적 6·7음은 비화성음으로 오인하지 않는다.

두 함수는 기보 시점의 관찰이다. 최고·최저음의 외곽선은 실제 내성의 자동 추적과 다르다. 비화성음 분류는 발음 시점에 한정하며, 붙임줄 아래에서 화성이 바뀌는 모든 불협화음·강약·계류·전타·악구를 평가하지 않는다. 연속된 비화성음 둘을 거치는 3·13마디 E–D–D♭–C는 이번 세 음 분류 범위 밖에 둔다.

| 비교 | 이전 | 수정 |
|---|---|---|
| 오른손–왼손 저음, 같은 방향 / 전체 비교 사건 | 20 / 106 | 10 / 118 |
| 오른손–왼손 최상음, 같은 방향 / 전체 비교 사건 | 21 / 106 | 13 / 85 |
| 양손이 함께 기보음을 유지한 길이, 4분음표=1 | 72.5 | 84 |
| 저음 외곽선의 완전5·8도 병행 후보 | 2 | 0 |
| 경과음 / 보조음 / 반음 접근 / 미분류 | 12 / 3 / 3 / 3 | 15 / 6 / 5 / 2 |

분모는 한쪽 또는 양쪽이 유지되는 사건도 포함한다. 반주를 바꾸면서 비교 가능한 사건과 기보 지속시간도 달라졌다. 수치 감소나 장식음 개수를 품질 점수로 쓰지 않는다. 기본 강박 검사는 보조음과 연속 반음 접근을 충분히 분류하지 못해 2→7개 경고를 남기며, 이 결과를 숨기거나 새 관찰로 덮어쓰지 않았다. 두 검사의 범위는 다르다.

## 자료 활용과 근거

이전에 읽어 둔 Weimar 독주 전사 456개 성부에서 인접 음정 200,353개 중 1반음 이동은 53,371개, 1–2반음 이동은 108,927개였다. 음정 관찰만 참고했으며 해당 음이 모두 비화성음이거나 좋은 재즈 선율의 정답이라는 뜻은 아니다. Weimar의 실제 연주 시간 단위는 초이고 이를 박으로 오독하지 않았다. 악구를 가져다 붙이거나 반주 라이브러리를 새로 검색하거나 모델을 학습하지 않았다.

작곡 원리 참고는 Open Music Theory의 [장식음](https://viva.pressbooks.pub/openmusictheory/chapter/embellishing-tones/), [재즈 보이싱](https://viva.pressbooks.pub/openmusictheory/chapter/jazz-voicings/)이다. 앞뒤 안정음과의 연결, 3음·7음 등 가까운 성부 연결을 참고했고 특정 작품의 예외 규칙은 만들지 않았다.

다음 작성에서도 먼저 베이스·화음 윗성부·주선율을 따로 불러 볼 수 있도록 쓴다. 같은 방향 진행이 이어지는 곳은 문장상 의도인지 확인하고 필요하면 반진행·유지음·시차 응답을 사용한다. 비화성음은 어디서 들어와 어디로 가는지 적고, 길게 머물 텐션과 연결용 짧은 음을 구별한다. 재즈 요소는 곡의 정서와 문장 역할에 맞게 선택한다. 쉼·반복·반진행·반음에 일정 비율을 강제하지 않는다.
