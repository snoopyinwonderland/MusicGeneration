# 기존 피아노 자료를 소품 작곡에 사용하기

현재 상태: **선택 기능 구현·기능 검증 완료 / 청취 품질 검수 전 / 기본 꺼짐**.

사용자 요청: “먼저 피아노 솔로 작곡에서 이전 학습 데이터들을 잘 활용하면 좋겠는데요.”

## 사용

```powershell
python -m musigen piece examples/pieces/lingering_light --out output/piano_corpus --reason "기존 반주 기준"
python -m musigen piece examples/pieces/lingering_light --out output/piano_corpus --corpus-accompaniment --preserve rh:1-24 motif:a --reason "피아노 자료 기반 반주"
```

기존 `piece` 동작은 바뀌지 않습니다. 대화에서 작곡 설계와 주제를 만든 뒤, 이 옵션으로 **계획한 반주 유형 안에서** 실제 자료의 왼손 반주를 선택합니다. 모형을 새로 학습하거나 전체 곡을 자동 작곡하는 기능은 아닙니다.

## 실제 사용하는 자료와 보존 범위

- musicomp의 기존 학습 분할 피아노 반주 라이브러리: 현재 로컬 인덱스 924곡, 왼손이 있는 76,929개 마디. 전체 행 77,716개와는 집계 기준이 다릅니다.
- 기존 `pacing_model.json`: 메타데이터에 250개 학습곡, 22,735마디로 기록된 밀도 모델. 프레이즈 위치, 종지 관찰, 쉼, 반복, 절정, 선율 활동도 등으로 반주 밀도 목표를 계산합니다. 모델이 없으면 기존 계획 강도를 사용하며 보고서에 `used: false`로 표시합니다.
- 기존 동기·프레이즈·종지 분석, 반주 검색 비용과 Viterbi 연결, 화음 역할에 따른 음높이 변환, 베이스·낮은 음역 정리를 그대로 재사용합니다. 조성과 화성은 작곡 악보에서 읽으며 재추정하지 않습니다.
- 작곡자가 준 `phrase_plan`과 `form` 경계, 절정 위치를 우선합니다. 프레이즈 계획이 없으면 기존 선율 분석을 사용합니다. 자동 종지 관찰은 의도한 종지와 구분합니다.
- 오른손 두 성부, 주제·쉼·표현·화음 계획은 보존합니다. 왼손도 직접 쓴 음, 동기, 둘째 성부, 쉼, 마디를 가로지르는 지속음, 못갖춘마디는 보존합니다. 생성된 `pattern` 반주만 교체합니다.

반주 유형은 기존 musicomp 분류기로 원래 반주와 후보를 동일하게 분류해 비교합니다. 분류는 held/block/stride/alberti/arpeggio/pulse/bass/mixed의 큰 범주입니다. 예를 들어 왈츠가 block으로 분류될 수 있어 원래 리듬을 똑같이 보존한다는 뜻은 아닙니다. 처음의 무제약 시험에서 긴 화음으로 쏠려 구간 대비가 약해졌으므로, 계수를 조정하는 대신 작곡자가 이미 선택한 유형을 검색 조건으로 사용합니다.

대응 자료가 없거나 연주 범위·난이도·성부 겹침 조건을 통과하지 못하면 해당 마디의 원래 반주를 유지합니다. 현재 곡 제목과 가져온 모티프의 출처 파일 제목은 검색 제외 목록에 넣습니다. 제목 기반 제외이며 모든 유사 작품을 판별하는 기능은 아닙니다.

## 결과를 다시 만드는 방법

`score.json`의 `corpus_accompaniment`에는 선택한 왼손 음표와 원래 왼손의 보존분을 분수 음가로 고정 저장합니다. 이후 `build`, `listen`, `duet`은 이 스냅샷을 사용하므로 라이브러리가 바뀌거나 없어져도 반주를 다시 선택하지 않습니다.

설계나 원래 악보를 수정하면 입력 지문이 달라져 낡은 반주의 재사용을 거절합니다. `--corpus-accompaniment`로 다시 선택하거나, `corpus_accompaniment` 필드를 삭제하면 원래 작성한 반주를 사용합니다. 스냅샷이 있는 버전을 `piece`의 입력 폴더로 주고 같은 옵션을 사용해도 원래 작성한 악보에서 다시 선택합니다.

별도의 `accompaniment.json`에는 다음을 기록합니다.

- 라이브러리 경로·SHA-256·곡/행 수, 밀도 모델 사용 여부·학습 규모·SHA-256, 검색/밀도 코드 SHA-256
- 마디별 계획 유형, 선택한 자료 곡·마디·유형, 검색 비용과 이유, 밀도 목표
- 적용 마디와 원래 반주를 유지한 이유, 사용한 프레이즈·구간·종지 관찰

`applied_bars`는 자료를 적용한 마디입니다. 적용 후 음표가 원래 것과 같을 수도 있으므로 실제 음표 변경 마디는 `version.json.changed_bars`와 구별합니다.

## 한계와 다음 검수

현재는 오른손 첫 성부가 단선율인 피아노 곡을 지원합니다. 오른손 첫 성부에 화음이나 겹치는 음이 있거나 한 프레이즈 전체가 쉬면 명시적으로 거절합니다. 자료 라이브러리 자체가 없으면 실패하며 사용한 것처럼 보고하지 않습니다. 자동 압축 해제나 musicomp 저장소·캐시 수정은 하지 않습니다.

DCML/classical_works, 합주 역할/전환 검색 실험, 네 편성 생성 결과의 재학습은 이 경로에 연결하지 않았습니다. 해당 실험 검색 옵션이 켜져 있으면 생성을 거절합니다. 보류된 계수 조정이나 성부 진행 실험도 채택하지 않습니다.

이 옵션은 반주 후보 생성입니다. 검색 비용, 반주 다양성, 자동 검사 통과가 음악적 우수성을 보장하지 않습니다. 기존 검사는 병행음정 등을 보고하지만 모든 경고 후보를 자동 재검색하지 않습니다. 학습 자료를 사용하는 다음 단계는 선율·화성·반주를 함께 평가하는 후보 비교이며, 우선 같은 주제의 전후 청취 의견을 수집해야 합니다. 생성된 곡이나 평가되지 않은 출력은 좋은 예제로 자동 편입하지 않습니다.
