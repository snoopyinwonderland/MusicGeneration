## P1–P5를 어떻게 이어 가는가

- P1/P2의 자동 후보 확장은 중단 상태를 유지한다. 이번에는 작성자가 짧은 주제를 설계하고, 각 구절에 다른 목적과 도착음을 주며 실제 음표로 반복을 확인한다. 과거 거절 후보를 선택으로 바꾸지 않는다.
- P3의 자동 프레이즈 경계는 재통과로 간주하지 않는다. 음정·음가·쉼·윤곽은 명시 선율의 실제 사건에서 직접 측정한다. 구절 통계는 사람 주석이나 명시 가사 줄 등 근거가 있는 경계만 사용하고, 고정 길이 창은 프레이즈라고 부르지 않는다.
- P4 모델 시험은 선율 표현과 평가 기준을 먼저 마련한 뒤 재개한다. 모델이 없어도 작곡과 검증은 진행한다. 이번 표본의 성공을 자동 모델의 완성으로 보고하지 않는다.
- 가사–선율–정서 연결은 별도 후속 실험으로 둔다. 이번에는 가사 부착 성부와 tick을 식별에만 사용하며 정서 학습 완료로 기록하지 않는다. 주석 근거와 보류 표본을 마련한 뒤 평가한다.
- P5는 다섯 곡에 대한 실제 의견을 축적한다. 자동 검사 통과, 청취 선호, 기본 적용은 서로 다른 상태다.

## 자료의 역할과 인기의 해석

기존 목록은 69개 루트/1,006,486파일이며 곡 수가 아니다. 압축본·판본·이조·편곡·MIDI 연주와 기보 악보가 섞여 있다. 전체 목록을 조사하되 지원하지 못한 형식과 주선율을 특정하지 못한 성부는 이유를 남긴다. 다성부의 최고음을 임의로 주선율 정답으로 삼지 않는다.

KYSing 사용은 Composition `DEVELOPMENT_LOG.md` #175의 2026-11-09–10 사용자 원문 “KYSing 데이터도 그냥 쓰세요 … 가사와 연결되는 멜로디에서 모티프와 프레이즈의 구조”와 이번 요청에서 확인했다. 로컬 분석을 선택 실행하며 기존 AGENTS의 ‘권한이 확인될 때까지’ 조건이 충족된 범위다. AI Hub 제외는 유지한다. 가사 본문은 새 분석 산출물에 복사하지 않는다.

TJ의 노래방 이용 횟수, Billboard의 차트 성적, Classic FM의 청취자 투표를 별도 표본 선정 근거로 쓴다. 각 집계의 시기·지역·방식을 보존한다. 인기만으로 선율의 우수성이나 인과관계를 주장하지 않으며, 제목이 같은 다른 작품을 자동 결합하지 않는다. 코드 라이선스를 모든 악곡의 권리로 확대하지 않는다.

## 선율과 화성 설계 원칙

주제의 원형 반복과 변형 재현을 모두 사용할 수 있다. 적절한 간격의 재현은 청자가 주제를 기억하고 곡의 귀환을 알아듣는 역할을 한다. 단순해질 때는 뒤따르는 음, 리듬, 도착음, 음역, 화성, 베이스, 반주, 문장 길이 중 음악적으로 필요한 것을 바꾼다. 긴 구절의 반복도 횟수만으로 거절하지 않고 위치와 앞뒤 맥락을 검토한다. 반복 검사는 자동 삭제·벌점·탈락 기준이 아니며, 반복 0회가 목표도 아니다.

높은 음을 계속 추가하는 대신 도약 뒤의 방향, 긴 음과 짧은 음의 대비, 쉼과 다음 구절의 진입, 정점으로 가는 길을 설계한다. 화성은 선율의 긴 음·강박음·비화성음의 진행을 먼저 검토해 붙인다. 세컨더리·차용·증6화음·국소 조성 이동은 도착과 해결이 있는 곳에 사용한다.

유사도 검사는 비교한 자료와 표현 안에서의 일치·근접 후보를 보고한다. ‘세상의 모든 음악과 다르다’거나 법적 독창성을 보증하지 않는다. 동일 작품의 판본 중복을 분리하고 학습/평가 자료를 섞어 성능을 부풀리지 않는다.
