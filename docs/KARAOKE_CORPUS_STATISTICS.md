# 노래방 전체 주선율·화성 통계

## 완료한 범위

[전체 표와 분모 보기](http://127.0.0.1:8808/karaoke-statistics.html). 전체 50,874개 파일을 처리했고 남은 파일은 0개다. 유효 파일 50,550개에서 전체 선율의 정확한 리듬·상대 음높이 지문으로 중복을 제거한 50,459개를 분석했다. 독립 작품을 완전히 식별한 수는 아니다. 조표·화성까지 포함한 지문은 50,505개라 화성 분석의 분모는 별도로 표시한다.

원 주선율 19,923,912음 중 랩 자리표시 의심 2,622,402음을 제외하고 17,301,510음이 남았다. 10,887개 선율에 해당 구간이 있고 630개는 제외 후 유음 선율이 남지 않는다. A4 연속 8음 이상의 휴리스틱이므로 실제 가창의 반복음을 제외할 수 있고, 다른 방식으로 기록한 랩을 모두 검출한다는 뜻은 아니다. 제거 구간을 건너뛰어 가짜 음정이나 음형을 만들지 않았다.

4·6·8음 음정/contour/음가 묶음, 4음의 정확한 리듬, 앞뒤 음정 전이, 쉼·마디 위치, 2·4·8마디 반복·변형, 화음 종류·근음 전이·3/4화음 진행·선율과의 관계를 59개 통계 계열로 저장했다. 정확한 패턴별 집계 행은 3,481,274개이며 이는 독립 음악 패턴의 수가 아니다. 검색 가능한 2·4마디 구간은 1,525,867개다. 8마디는 반복 관찰만 저장했고 검색 구간 목록에는 넣지 않았다.

## 중요한 자료 한계

**분석에 포함된 모든 선율에서 MIDI 장·단조 비트가 0이었다.** 실제 곡이 전부 장조라는 의미로 사용할 수 없다. 따라서 `degree_progression_*`의 `major` 접두어는 원본 비트이며, 근음 숫자는 조표의 관계장조 기준점에 대한 반음 거리로만 읽는다. 실제 으뜸음·국소 조성·종지·세컨더리 화음의 정답 라벨로 쓰지 않는다. 근음 이동·화음 구성음은 이 장단조 비트에 의존하지 않는다. 다음 기능화성 학습 전에 장단조/국소 조성 표본 검증이 필요하다.

화음 라벨을 하나라도 해석하지 못한 선율은 3,860개, 해석 가능한 코드가 전혀 없는 선율은 50개다. 미해석 라벨 구간을 직전 코드로 채우거나 새 코드를 추정하지 않는다. 구성음 통계는 라벨의 음악적 정확성을 보증하지 않는다. 쉼으로 나눈 구간·마디 창·원본 화면 줄바꿈/섹션 마커도 서로 다른 자료다.

2·4·8마디 비교는 명시 박자에 맞춘 비중첩 창이다. 최소 4발음, 창 경계를 가로지르는 음과 랩·겹침이 없는 창만 채택했으므로 모든 구절의 무편향 표본이 아니다. 장르·언어·인기도를 통제하지 않은 전체 코퍼스이며, 곡의 좋고 나쁨이나 사용자 선호는 이 빈도로 정하지 않는다.

## 다음 생성 방식에 적용할 순서

1. **묶음 단위 검색**: 4–8음 미세 음형과 2–4마디 구간의 리듬·도약 위치·최고음·끝음 길이·쉼·화성 문맥을 함께 조회한다. 완전 이식과 특징 참조를 구별해 출처를 남긴다.
2. **구절 역할 검수**: 시작·응답·고조·종결 후보를 만들고, 원본의 앞뒤 구간과 함께 검토한다. 현재 쉼 경계를 자동 프레이즈 정답으로 승격하지 않는다.
3. **변형 관계부터 설계**: 음 하나씩 전개하기 전에, 어느 묶음을 되받고 어디서 음역·리듬·끝부분을 바꿀지 정한다. 관찰된 반복률을 강제 비율로 쓰지 않는다.
4. **분리 평가**: 전체 선율/작품 중복이 학습·검증 양쪽에 새지 않도록 나누고, 같은 입력에 대한 기존 방식과 묶음 방식의 청취 후보를 비교한다. 실제 장단조를 검증한 뒤 기능화성·종지 조건을 연결한다.

이번 꾸러미는 전수 통계와 검색 자료 구축 완료다. 새 곡, 신경망 학습, 자동 역할 분류, 생성 품질 개선 검증, 기본 생성 방식 적용은 아직 하지 않았다.

## 개발 기록

- 2026-11-18: `codex/karaoke-corpus-statistics` 시작. 원본 수와 파생 자료 관계, 기존 자료 분석 코드 및 Composition의 KYSing 변환기·안내서를 확인했다. 원본 화음과 자동 추정 화음을 구별하고 랩 의심 구간을 제외하는 분석을 설계했다.
