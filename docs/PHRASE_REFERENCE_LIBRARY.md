# 프레이즈 참조 자료 · 선택 관찰

`phrase_reference`는 TAVERN의 사람이 나눈 악구 파일을 읽어 주제–변주 대응 후보, 원 주석의 내용 관련성, 마지막 음의 길이와 뒤 쉼을 정리합니다. 원곡 음열을 출력하거나 작곡가 스타일을 학습하지 않습니다. 각 악구가 문장형의 어느 역할인지는 자동으로 붙이지 않습니다.

```powershell
$env:MUSICOMP_ROOT='K:\Music Composition'
python -m musigen.phrase_reference --root 'K:\MusicSearch\data\classical-corpora\tavern' --works B070 M025 M179 M265 M573 --out output/library-v001/references.json
python -m musigen.phrase_reference --library output/library-v001/references.json --query rest
```

조회는 `rest`(끝 쉼 있음), `held_end`(마지막 음가가 앞 유음 음가 중앙값보다 큼), `related`(원 파일명의 내용 글자가 같은 악구), `variation`(같은 악구 순번의 주제–제1변주)입니다. 정렬 점수나 자동 선발 기능은 없습니다. 끝 음가가 길다고 종지 종류를 결정하지 않습니다.

화성·기능 주석은 두 분석자를 따로 보존합니다. **function/**harm 필드의 원 토큰, 기능 라벨 순서, 마지막 화성 토큰, 조성 토큰만 읽습니다. 음표와의 시간 정렬, 비표준 로마자 수정, 종지 종류 추정은 하지 않습니다. Humdrum 성부 분기/병합이 있으면 해당 주석은 미평가로 남깁니다. 악보의 단선율 관찰과 주석 파싱 성공 여부도 별개입니다.

2026-11-11 관찰: 지정한 5작품의 주제·제1변주 악구 40개 중 36개를 읽었습니다. 4개는 기존 단선율 조건에서 제외했습니다. 주석 80개 중 56개를 읽었고 성부 분기/병합이 있는 24개는 제외했습니다. 주제–제1변주 대응 후보는 14쌍, 내용 관련성은 4쌍입니다. 이것은 전체 코퍼스의 대표 표본이나 생성 품질 평가가 아닙니다.

실제 참조 예:

- B070 주제 악구 1: 마지막 유음 1.5박, 앞 음가 중앙값 0.5박, 끝 쉼 1박. 두 분석자 모두 기능 T→P→D, 마지막 화성 원 토큰 `4V`.
- B070 주제 악구 2: 끝 쉼 1.5박, 기능 T→P→D→T, 마지막 `4I`. 이를 질문/응답 설계에 참고하는 것은 작성자의 해석입니다.
- M025 주제 악구 1·3: 두 분석자가 같은 내용 글자로 연결. 정확히 같은 음표라는 뜻은 아닙니다.
- M265 제1변주 악구 1: 짧은 음들이 이어져도 끝 음은 앞 음가 중앙값의 4배이고 뒤에 1박 쉼이 있습니다.

조각내기·음가 확대를 새로운 모티프에 적용할 수는 있지만, 이번 관찰에서 자동 검증한 기법으로 표시하지 않습니다. 기존 모티프 연산을 사용한 작성자의 선택입니다. 참고한 사실과 작성자의 적용 결정은 별도 기록합니다.
