## 2026-11-18 · 노래방 전체 주선율·화성 통계 — 집계 완료, 생성 적용 전

- 요청: 50,874개 원본 노래방 MIDI에서 음형·음정·contour·화음 진행을 조사하고, 음 한 개씩 무작위로 만드는 방식 대신 묶음의 발전에 근거를 마련한다. 랩은 제외한다.
- 브랜치: `codex/karaoke-corpus-statistics`, 기준 `e34aa95`.
- 구현: 선택 실행 모듈 `musigen/karaoke_statistics.py`. 원본 S1/channel 4, 원본 코드 트랙, 명시 조표·박자를 읽는다. 파생 XML을 중복 작품으로 더하지 않는다.
- 단위: 4·6·8음의 음정·contour·음가 묶음, 4음의 정확한 리듬, 2·4·8마디의 반복·이조·리듬 유지·종결부 변형. 1박 쉼 기준 구간은 검증된 악구가 아니며 0.5·2박 경계 수와도 비교한다.
- 범위: 주선율 통계의 랩 의심 A4 반복을 제거한다. 제거 구간을 가로질러 가짜 연결을 만들지 않는다. 명시 화음과 선율의 동시 관계를 조사하며 화음을 추정해 채우지 않는다.
- 검증: 합성 사례 7개 통과. 40개 파일 시범 분석 통과 후 전체 50,874개 실행 시작. 전체 테스트 281개 중 기존 외부 프레이즈 분절 기대치 차이 1건은 남아 있다.
- 후속 검증: 두 MIDI 파서가 같은 음 재발음의 종료 시점을 다르게 해석한 표본을 확인했다. 해당 파일 유형을 제외하는 v2 검증과 회귀 테스트를 추가했다. 전체 50,874개 읽기는 완료, 50,550개 분석 가능·324개 사유별 제외. 최종 표본 64개는 파서 대조 및 특성 재계산 모두 일치했다.
- 분석 계획과 실제 결과: [노래방 통계](KARAOKE_CORPUS_STATISTICS.md). 완성곡·모델 학습·생성 기본값 변경은 이번 작업에 포함하지 않는다.
- 완료: 선율 지문 중복 제거 후 50,459개, 랩 의심 구간 제외 후 17,301,510음. 59계열의 통계와 1,525,867개 2/4마디 구간을 로컬 DB에 구축했다. 곡별 가중치와 구절 중복 가중치도 비교했다.
- 발견: 분석 대상의 MIDI 모드 비트가 모두 장조로 기록돼 있다. 실제 장단조와 종지 정답으로 해석하지 않으며 기능화성 학습 전에 별도 검증한다.
- 최종 검증: 새 테스트 9개 통과. 전체 283개 중 282개 통과, 기존 외부 프레이즈 분절 차이 1개 실패. 64파일 파서 대조·재계산 일치, SQLite 무결성 정상, 원본 50,874개 규모·수정시각 유지. 보고서 HTTP 200과 목록 연결 확인, 브라우저 도구 미연결로 시각 검수는 미실시.
