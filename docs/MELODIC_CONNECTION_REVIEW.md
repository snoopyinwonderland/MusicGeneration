# 선율 연결 비교와 청취 의견

기존 완성곡의 모티프·화성·왼손·표현을 고정하고 선율을 직접 수정하는 선택 경로입니다. 「엘리제를 위하여」 연결 피드백을 계기로 추가했지만 곡 이름에 따른 코드 분기는 없습니다. 기존 `piece` 생성 방식은 바뀌지 않습니다.

`python -m musigen.phrase_review --baseline <기존 출력> --work <수정 입력> --out <새 비교 폴더> --protected-bars 1`

`comparison.json`의 `melodic_connections`는 마디 경계의 실제 음정, 쉼 길이, 음가 중앙값 비율, 마디 안 최대 도약을 기록합니다. 빈 마디는 음을 만들어 채우지 않고, 겹친 오른손 성부를 임의로 줄이지 않습니다. 관찰값에는 품질 임계값·순위·자동 선택이 없습니다. 작곡자는 원형의 리듬과 꼬리, 앞뒤 음역, 종지를 함께 검토해야 합니다.

비교 페이지에는 A, B, 둘 다 다시 다듬기, 아직 결정하지 않음을 고르는 의견 칸이 있습니다. 처음에는 아무것도 선택하지 않습니다. 의견 JSON은 비교판 지문·후보 목록·작성 시각·이유를 포함합니다. 받은 파일은 다음 명령으로 기록합니다.

```powershell
python -m musigen.review_choice --comparison <비교 폴더> --selection <직접 내보낸 의견 JSON>
```

입력 지문, 네 악보 파일의 SHA-256, 표시 후보와 선택의 일치 여부를 검증합니다. 동일 의견을 다시 가져와도 중복 기록하지 않습니다. 시험용 내보내기는 거부합니다. 거절·보류는 `chosen=null`로 남으며 성공 선택으로 바꾸지 않습니다. 출처는 입력 JSON에서 신뢰하지 않고 비교 명세에서 가져옵니다. 파일은 서명된 사용자 인증 수단은 아니므로 실제 전달받은 의견에만 import를 실행해야 합니다.

이 비교는 기존판과 수정판을 명시하는 공개 비교입니다. P4의 모델·규칙 생성기 눈가림 비교를 대신하지 않습니다. 선택 이력은 `selections.jsonl`에 쌓을 뿐 자동 학습이나 후보 순위 변경에 사용하지 않습니다.
