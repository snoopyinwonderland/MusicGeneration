# 11–20번 선율 후보 검수 요청

브랜치 `codex/melody-phrase-round2` · 기준 `3d40b9d`. 사용자는 01–10번 중 “4, 5, 6, 8은 좀 괜찮고 나머지는 아닙니다”라고 말했다. 의견과 악보의 측정값을 `docs/MELODY_LISTENING_FEEDBACK.md`에 함께 남기고, `docs/COMPOSING.md`에서 이후 단선율 작업에 참고하도록 연결했다. 이번의 청취 표본은 10개이며 선호의 원인이나 범용 규칙을 확정하기에 작다. [이전 후보](http://127.0.0.1:8808/melody-phrases/index.html)

새 후보 11–20번은 각각 네 마디의 단선율이다. 04의 도약 뒤 방향 전환, 05의 반음계, 06의 여백, 08의 6/8과 밀도 변화를 여러 박자와 조성에 나누어 썼다. 12번의 2–3마디에서는 길게 쉬고 반음 진행으로 다시 시작한다. 13번은 1마디부터 2분음표를 두었고, 14번은 3마디를 빠르게 꾸민 뒤 네 번째 마디에 두 음과 쉼을 두었다. [새 후보 목록](http://127.0.0.1:8808/melody-phrases/round2.html)

`docs/listen/melody-phrases/phrases-round2.json`에 원본 선율과 빠르기를 기록했다. 같은 폴더의 `round2.html`은 연주 버튼과 한 보표짜리 악보, `index.html`은 새 후보로 가는 링크를 제공한다. 8808 라이브러리에 양쪽을 연결했다. 새 페이지의 `decodeSamples`와 `play`는 이전과 같은 피아노 샘플 방식으로 재생한다. 작곡 엔진의 자동 생성 계수는 건드리지 않았다.

MusicXML을 다시 읽어 새 40마디의 음높이·온셋·음가·쉼을 대조했다. 브라우저에서 10개 후보의 악보, 재생 시작, 전환·정지와 이전 목록에서의 진입을 확인했다. 단위 테스트 274개가 통과했다.

기존 색인 791,135개 성부에 대해 두 마디 이상 연속 12음 일치와 16음 근접 일치가 모두 0건이었다. 이전 작성본 질의 47개와 새 후보, 새 후보끼리의 연속 8음 음정·리듬 일치도 0건이었다. 검사는 이조와 일정한 템포 배율을 허용한 해당 창에 한정된다. 원본 MusicXML, 대조 보고서와 제작 도구는 로컬 `output/melody-phrase-round2/`에 있다.
