## 실제로 참고한 자료

TAVERN 로컬 27작품 중 현재 glob `*/*/Krn/*_00_01_score.krn`에 맞는 첫 악구 25쌍을 시도했습니다. 엄격한 단선율·박자·길이 조건으로 5쌍을 관찰했고 20쌍은 제외했습니다. 나머지 2작품을 관찰했다고 세지 않습니다. 이 수치는 전체 변주·악구의 분석률이 아닙니다.

- 명시적 작곡 참조는 Mozart K.25와 K.265 두 쌍뿐입니다.
- K.265 주제/제1변주: 붙임줄 통합 후 16/51 공격점, 16박, 이웃음 왕복 0/14 및 10/49 창. 주제와 같은 시점의 음고류 일치는 2/13에 불과하므로 이 지표를 주제 동일성 점수로 해석하지 않습니다.
- K.25 주제/제1변주: 27/35 공격점, 24박, 공유 공격점 27개 중 음고류 일치 24개.
- `Joined` 두 분석자 자료는 각각 경로·해시를 보존합니다. 해당 로마자 분석을 파서가 읽었다고 주장하지 않습니다. `Krn`의 악보만 읽었습니다.
- 자료 출처: [TAVERN](https://github.com/jcdevaney/TAVERN), Devaney 외, CC BY-SA 4.0. 출력에 LICENSE 사본을 포함합니다.
- 새로운 카탈로그의 `generation_eligible`을 true로 바꾸지 않았습니다. 신경망 학습·통계 모델 적합·holdout 품질 평가는 하지 않았습니다. BPS와 MIDI 목록을 이번 작곡에 사용했다고 주장하지 않습니다.

## 검증

- 전체 unittest: 131개 통과(20.314초).
- XML: 요약 악보 A 39음/B 43음, 화성 각 10구간과 조성 1영역 정확 왕복. 독주도 철자·음가·성부·음표 재읽기 일치.
- 프레이즈 분석: 양쪽 모두 1–4, 5–8마디로 관찰. 쉼 5박. 이는 청취 품질 판정이 아닙니다.
- 검사 오류 없음. A에는 3마디 G5/Am 및 6마디 D5/F에 기존 비화성음 분류 경고 2개가 남습니다. B에는 경고 없음. 경고 수 감소를 품질 향상으로 단정하지 않습니다.
- Verovio: 네 악보 모두 파싱 로그 없음. PDF 각 1쪽, 4+4마디. Poppler PNG로 최종 네 페이지를 시각 검수했습니다. Poppler의 시스템 Symbol/ArialUnicode 탐색 경고는 있었으나 실제 악보는 래스터 그림이고 한글은 내장 Malgun이므로 깨진 글자는 관찰되지 않았습니다.
- 브라우저: A/B 화면, 피아노 샘플 선택, 재생 상태, 보표 아래 Roman Numeral Analysis↔Chord Symbols, PDF·XML·WAV 다운로드 확인. 받은 PDF는 바이트 일치, XML은 개행 정규화 후 텍스트 일치.
- WAV 두 개: 44,100 Hz 모노, 각 약 19.01초. 최대 PCM16 진폭 11013/11015로 무음·클리핑 아님. 실제 연주자 표현 또는 청취 품질을 인증하지 않습니다.
- 원자료 재관찰 결과 일치. 최종 코드의 박자 검사에서 B064의 박자 누락을 제외하며 6쌍으로 집계했던 초기 중간 결과를 5쌍으로 정정했습니다.
- 테스트 첫 실행은 샌드박스 임시 폴더 권한 문제였습니다. `TEMP`/`TMP`를 작업 트리의 `output/test-temp`로 설정한 뒤 재실행했습니다. 기능 실패를 숨긴 것이 아닙니다.

## 재실행과 위험

사용법은 안내 문서 참조. PDF 제작 스크립트는 로컬 `output/render_comparison.mjs`, `output/build_comparison_pdf.py`에 남겼습니다. 최종 XML은 PDF 검수한 v002와 바이트 단위로 같고, v003은 출처 감사 집계와 입력 해시를 확정한 버전입니다. PDF·WAV·화면 캡처는 동일한 악보의 검수 산출물을 가져왔습니다.

감상 서버는 사용자 요청의 URL을 유지하기 위해 작업 후에도 127.0.0.1:8795에 남깁니다. 재부팅 뒤에는 다음 명령으로 다시 시작할 수 있습니다.

```powershell
& 'K:\Music Analysis\.venv\Scripts\python.exe' -B -m http.server 8795 --bind 127.0.0.1 --directory 'K:\MusicGeneration\motif-development\output\comparison-v003'
```

작곡가 스타일 전체를 대표하기에는 두 악구 참조가 작습니다. 상단 단선율이 실제 주요 선율이라는 전문가 주석도 아닙니다. 자료 분석 조건 때문에 다성적인 변주는 많이 제외됩니다. 주제 인식과 종지의 자연스러움은 사용자 청취 판단이 남아 있습니다. 이전 P3 자동 경계 모델이나 원곡 화성 인식 계수를 수정하지 않았습니다.

검수 후에도 기본 생성 방식에 자동 적용하지 않습니다. 다음 꾸러미는 사용자가 선호한 방향을 바탕으로 곡 전체의 프레이즈 구조와 상세 왼손 화성 계획을 작성하는 단계입니다.
