# 실제로 이어진 두 마디를 이용한 선율 발전

`codex/karaoke-adjacent-phrases` · 2026-11-18 · [작곡 작업실](http://127.0.0.1:8808/compose.html)

## 분석

노래방 원본 50,874개를 조사한 기존 전체 통계 DB를 읽기 전용으로 사용했다. 원본 판독 제외 324개, 선율 지문 중복 제거 후 50,459개 선율의 인덱스다. 기존 필터는 랩 의심 구간, 마디 경계를 가로지르는 지속음, 중첩 발음, 4발음 미만 창 등을 제외한다. 박자 구간에 정렬한 비중첩 2마디 창 994,175개 전체를 곡·시작 시각 순으로 순회했다. 같은 곡에서 길이가 같고 끝·시작 틱이 일치하는 761,998쌍, 기여 선율 47,260개다. 서로 떨어진 창을 이어 붙이지 않았다. 길이가 같은 서로 다른 박자는 구별되지 않으며, 빈도는 출현 수 가중이다.

선행·후행 2마디 각각의 첫음과 끝음 차이(±2반음 이내는 수평), 발음 밀도(6음 이하, 7~11음, 12음 이상), 경계의 마지막 음→다음 첫음 간격(±7에서 절단)을 함께 집계했다. 예를 들어 고밀도 상행 65,211쌍 다음에는 고밀도 하행 17,986회, 고밀도 수평 16,164회, 고밀도 상행 9,476회였다. 방향은 구간의 순변위다. 자연스러운 프레이즈의 경계 또는 선율 품질에 대한 라벨은 없다.

기존 DB의 인접 관계 집계는 같은 길이 조건을 추가하기 전 762,132쌍이다. 상대음형과 리듬이 모두 바뀐 경우 728,316회, 리듬만 같은 경우 22,847회, 상대음형만 같은 경우 1,606회, 완전 동일 8,804회, 전체 이조 559회였다.

재현 명령은 저장소 루트에서 다음과 같다.

```powershell
python musigen/karaoke_neighbors.py output/karaoke-statistics-20261118/statistics.sqlite3 musigen/data/karaoke_neighbors.json
```

## 작곡과 검수

작업실의 ‘선율 발전 방식’에서 **노래방 인접 두 마디 통계**를 선택한다. 기존 방식이 초기 선택이다. 입력한 주제를 제시한 뒤 직전 두 마디의 방향·밀도에 따라 다음 구간의 목표 방향·밀도와 진입 음정을 함께 뽑는다. 노래방 네 음 음정·리듬 통계로 16개 후보를 만들고 목표와의 일치, 직전 구간의 음가열 중복을 비교한다. 중간 지점에는 첫 음부터 최대 세 사건의 짧은 단서를 재현하고, 끝에는 으뜸음에 착지한다. 후보 수, 중간 주제 재현과 종결은 설계 선택이다. 확률 학습 결과는 인접 구간 전이표다. 한 마디 미만 입력은 기존 두 마디 이어쓰기를 거친다. 새 선율을 대상으로 기존 화성화를 적용한다.

같은 E♭장조 모티프, 4/4, ♩=92, 시드 118로 생성했다. 각 2마디의 발음 시작 위치열을 비교한 결과이며 선호 점수는 아니다.

XML을 재해석해 악보 길이와 마디 수를 확인했다. 3/4·4/4·6/8 각각 8·16마디에서 주제 보존, 양의 음가, 총길이와 리듬 변화를 검사했다. 전체 테스트 292개 중 291개 통과, 기존 외부 프레이즈 분절 기대값 차이 1개. 청취 선호는 사용자 검수 대기다.
