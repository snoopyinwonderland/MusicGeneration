# 검수 요청: Uptown Girl 메인 테마의 모차르트 참조 소품

- 브랜치: `codex/uptown-mozart-study`, 기준 `5c8b40f`.
- [감상과 두 악보](http://127.0.0.1:8808/uptown-mozart.html), [제작·검증 기록](../../UPTOWN_MOZART_STUDY.md).
- 상태: 작성 v004 / 전달 v002, 기술 검증 완료, 사용자 청취 검수 전. 기본 생성·main 변경 없음.

## 무엇을 왜 바꿨나

사용자가 Uptown Girl의 전주가 아닌 메인 테마로 모차르트 스타일의 새 작곡을 요청했다. 보유 악보 9–10마디를 확인해 첫 제시에 보존하고, 새 주제 발전·화성·반주를 직접 작성했다. 32마디 E장조–B장조–E장조, ♩108, 페달 없음. 모차르트 마디 검색과 K.265·K.25 변주 관찰을 실제 실행했으며 음표 검색 편곡이나 새 학습 모델과 구별했다.

## 변경 파일·함수

- `docs/UPTOWN_MOZART_STUDY.md`: 모티프 선정, 자료와 작성 판단, 구간 계획, 검증·한계.
- `README.md`: 최신 작품 링크.
- 이 검수 요청서. 공통 코드 함수 변경 없음.
- Git 제외 `output/uptown-mozart/author.py`, `finish.py`: 원본 추출·독립 대조, 실제 참조 조회, 직접 작곡, 악보·PDF·감상 페이지 제작. 원본 악보·음표·PDF·WAV·자료 인덱스를 커밋하지 않는다.

## 전후와 들어 볼 곳

신규 작곡이며 다른 곡의 A/B 수정이 아니다. 원본 9–10마디는 새 곡 1–2마디에 동일하게 나온다. 5–8 응답, 9–16 딸림조 구간, 17–24 장식·정점·여백, 25–32 변형 재현과 종결을 듣는다. 중간본은 보존했고 최신 감상 URL은 전달 v002로 연결했다. 기존 Count On Me 감상본은 변경하지 않았다.

## 검증

266개 Python 테스트 통과. 두 악보 XML 왕복 일치, 첫 모티프 8박·9발음·쉼 보존. 134개 주선율 발음·39개 화성·세 조성 구간 대조. 실제 LH 최대 폭 10반음·구성음 누락 0. 쉼을 끊는 외성 병행 완전음정 관찰 0/0. PDF 2개 각 1쪽 시각 검수와 실제 재생·다운로드 확인. 다운로드 XML/PDF 대조, WAV 70.971초·비무음·포화 없음 확인. HTTP 자원 해시는 별도 검증 JSON에 남긴다.

## 위험·남은 일

- 자동 스타일 편곡기는 구현하지 않았다. 초기 참조 검색은 첫 마디의 단순 특징 거리이며 모차르트 고유성의 검증 점수가 아니다.
- 솔로 경고 6개(강박 비화성음 미분류 5·쉼을 넘긴 병행 1), 화성 요약 경고 7개를 유지했다. 전체 내성·전문 연주 가능성 검수는 아니다.
- 입력 UI가 E major 요청을 지원하지 않아 독립 감상 URL을 제공했다. 작곡함 요청과 결합하는 UI 확장은 별도 작업이다.
- 원본 출처와 모차르트 자료 참조 범위를 보존했다. 청취 승인과 기본 적용을 기술 검증으로 대신하지 않는다.
