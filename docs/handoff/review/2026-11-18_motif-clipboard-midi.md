# 파일 구간의 모티프 JSON 복사 검수

2026-11-18 · `codex/motif-clipboard-midi` · [작곡 작업실](http://127.0.0.1:8808/compose.html)

‘악보 파일·DB에서 구간 선택’에서 MIDI(.mid, .midi), MusicXML(.xml, .musicxml), 압축 MusicXML(.mxl) 또는 기존 DB 악보를 연다. 파트·보표·성부를 선택하고 마디나 음표의 시작과 끝을 지정한다. ‘모티프 JSON 복사’는 현재 작성 중인 입력을 보존한다. 창을 닫고 모티프 입력 칸에서 Ctrl+V를 누르면 전체 클립이 들어가고 미리보기 악보를 갱신한다. ‘선택 구간 바로 쓰기’도 계속 사용할 수 있다.

- `workshop_file.py`에서 로컬 요청의 바이너리를 메모리로 읽는다. MIDI 형식 0·1의 박 기준 파일은 music21에서 16분음표 및 8분 셋잇단 기준으로 양자화하고 악보 파트를 만든다. 트랙 번호는 지휘 트랙을 포함한 파일의 1번부터 센다. MXL은 컨테이너가 지정한 악보 XML을 읽는다. 기존 XML 파일은 브라우저에서 바로 연다.
- `workshop_import.js`에서 복사와 바로 적용이 같은 구간 추출 함수를 사용한다. JSON은 musicanote-motif v1이며 파일명·파트·보표·성부·마디·오프셋을 기록한다. MIDI 변환의 양자화 방식을 함께 보관한다. 클립보드 쓰기가 차단되면 직접 Ctrl+C 할 수 있도록 JSON을 선택한다.
- `workshop.js`에서 유효한 모티프 JSON의 붙여넣기는 현재 입력 전체를 바꾼다. 저장한 원본 악보는 보존한다. 프레이즈 작곡과 편곡 엔진에는 변경이 없다.

## 검증

실제 8808 브라우저에서 두 연주 트랙이 있는 MIDI 중 ‘트랙 3’을 열어 첫 마디의 G4–쉼–A4(각 1박)를 복사했다. MXL에서 C3–쉼–D3(각 1박), ‘두 박에서 시작한 노래’ XML에서 E♭4(반 박)–쉼(반 박)–F4(한 박)를 확인했다. 복사 전후 작성 중인 C4 한 음이 유지되고, Ctrl+V 뒤에는 XML에서 고른 세 사건과 같은 악보가 표시됐다. 클립보드 쓰기 차단 시 수동 복사 입력란도 검증했다.

새 테스트 3개 통과. 전체 291개 중 290개 통과, 기존 외부 프레이즈 분절 기대 차이 1개가 남는다. 노래마다 다른 트랙 구성, 연주자의 미세한 타이밍, 자동으로 나눈 다성 성부는 가져온 악보에서 확인해야 한다.
