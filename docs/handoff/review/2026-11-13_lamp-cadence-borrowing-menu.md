# 「창가에 켜진 불」 종지와 모티프 적용 비율 검수 요청

브랜치 `codex/lamp-cadence-borrowing-menu` · 기준 `0672a75`. 사용자는 곡이 아직 평이하고 마지막 두 마디의 왼손이 급하게 끝난다고 했다. 모티프 적용 비율을 10~90%에서 선택하는 메뉴도 요청했다.

[종지 수정판](http://127.0.0.1:8808/listen/lamp-in-the-window/cadence/index.html#piece=lamp_cadence&version=v001)에서 **13–16마디 전후 듣기**를 누르면 이전판 v006의 끝부분과 현재 선택한 수정판을 차례로 재생한다. 메뉴의 0%는 이번 수정의 기준 선율이며, 이전판은 별도 항목에서 선택한다.

- 15마디의 왼손 발음을 네 번에서 두 번으로 줄였다. F에서 G로 두 박씩 받치고, 16마디에서는 낮은 C를 네 박 유지한다. 내성 C–E가 한 박 뒤에 약하게 들어오고, 오른손의 마지막 C는 온음표로 여운을 준다. 15–16마디의 여린 셈여림을 별도로 적었다.
- 2·6·10–11마디에 짧은 이웃음과 당김을 더했다. 2마디는 G–G7sus4–G7, 6마디는 Am7–Cmaj7/G, 10마디는 Cmaj7–G6–G7로 한 마디 안에서 바뀐다. 7마디에는 C–B–A로 내려오는 내성을 넣었다. 4·8·12마디의 쉼은 확인했다.
- `musigen/melodic_borrowing.py`의 `fit_options`는 마디 중간에 바뀌는 코드의 실제 위치를 계산해 그 시점의 구성음으로 후보를 평가한다. 비율별 선택은 기준 선율 위에 4–6음 상대 음정 모티프를 이조해 배치한다. 모든 비율에서 오른손 리듬, 마지막 C, 반주와 화성은 같다.
- `musigen/listen_template.html`은 `borrowing_percent`가 있는 악보를 제공할 때 메뉴를 **모티프 적용 비율**로 표시한다. 각 항목은 목표와 실제 적용 음수를 보여 준다. 10%부터 90%까지 10% 간격으로 선택할 수 있고, 음표 수에 맞춰 반올림된 범위를 적용했다. 실제 범위는 62음 중 6·12·19·25·31·37·43·50·56음이다.
- 0%와 아홉 비율의 MusicXML을 다시 읽어 보표·성부·음높이·시점·길이를 확인했다. 악보 검사 오류·주의 0건, 전체 테스트 273개 통과. PDF 10개를 한 페이지씩 시각 확인했고 브라우저에서 아홉 비율의 피아노 재생과 13–16마디 이전판→수정판 전환을 확인했다. 791,085개 성부에 대한 연속 12음 일치 및 16음 근접 일치가 10개 판에서 모두 0건이었다. 이 범위의 음표 유사도 검사다.

곡별 작업 파일은 Git 제외 `output/lamp-cadence`에 있다. `arrange.py`는 기준 악보와 선택 입력, `render.py`는 악보 및 검증 파일, `publish.py`는 청취 페이지를 작성한다. `input.json`에 적용 출처와 구간을 기록했다.
