# 그리움 청취 후보를 작곡 작업실에서 검수

- 브랜치 `codex/listening-pair-workshop`. 기존 비교 페이지의 첫 선택이 두 마디 구간이어서 전체 듣기와 입력기를 찾기 어려웠다는 피드백을 반영했다.
- `scripts/longing_listening_pair.py`에서 후보별 기존 MusicXML을 작업실의 표준 작품 폴더에 등록하고 첫 마디를 모티프 입력값으로 제공한다. 작품별 고정 ID로 다시 게시해도 목록에 중복되지 않는다. `scripts/longing_listening_pair.html`의 기본 재생 범위를 전체로 바꾸고 작업실 링크와 통계 적용 지점을 추가했다.
- [후보 A](http://127.0.0.1:8808/compose.html?piece=57ce9cee6a2f5b3bb37b75c2c649f5b6) / [후보 B](http://127.0.0.1:8808/compose.html?piece=d5c49e6c9cfc52e2b563615f02b1dc47). 입력기에는 첫 마디, 결과 악보에는 8마디가 표시된다. 악보의 듣기로 양손을 함께 재생한다.
- Edge에서 두 버전의 8마디, 입력기 음표, 각 58개 재생음과 최종 종료 시점 24초를 검사했다. 첫 병렬 검증에서 한 번 오류 상태가 관측되었고 재검증에서는 두 버전 모두 전곡 종료에 도달했다. 원인은 특정되지 않았다. Python 회귀 294/295 통과, 기존 프레이즈 경계 기대값 실패 한 건.
- 이번 변경은 청취 경로와 통계 설명에 적용했다. 첫 동기의 윤곽과 두 화음 연결을 집계에서 참고했고 전체 음표와 맺음은 수동 설계다.
