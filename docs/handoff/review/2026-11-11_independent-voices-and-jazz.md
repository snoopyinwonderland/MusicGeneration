## 무엇을 왜 바꿨는가

사용자는 첫 곡의 양손이 비슷한 contour로 움직이고 음악이 단순한 아동 노래처럼 느껴진다고 지적했다. 경과음·보조음으로 연결을 다듬고 재즈 화성·리듬을 섞는 요청에 따라 첫 곡 한 곡을 집중 수정했다. 다른 네 곡은 기존 v002를 유지한다.

- `musigen/voice_independence.py`: `contour`와 `embellishments`의 선택 관찰. 지속·해제·쉼, 실제 화음음과 비화성음의 앞뒤 관계를 구별한다. 자동 생성이나 수정 규칙으로 연결하지 않았다.
- `tests/test_voice_independence.py`: 유사진행과 완전 병행의 구별, 발음이 없는 시점의 쉼, 화음 해제에 의한 외곽선 변화를 선율로 오인하지 않음, 유지 베이스/명시적 6음, 연속 경과·보조음 및 쉼, 다음 화음으로의 반음 접근을 확인한다.
- `docs/INDEPENDENT_VOICES_AND_JAZZ.md`, `README.md`, `docs/COMPOSING.md`, `docs/PLAN_STATUS_2026-11-11.md`: 작성 원칙·수치·실행/청취/기본 적용 상태.
- 작성 악보·PDF·자료 관찰·A/B 페이지는 Git 제외 `output/`에 있다. musicomp·데이터셋·기본 생성·기존 경고 코드는 바꾸지 않았다.

## 전후 음악과 들을 곳

작성 v005→v007, 감상 전달 v002→v003. 첫 오른손 모티프 마디와 기본 조성·박자·빠르기·길이를 보존했다. 왼손은 베이스와 화음 성부로 새로 작성했다. 실제 유지음 포함 최대 손 벌림 11반음, 마지막 한 마디만 페달이다.

- 1마디: 오른손 A–C–D 상승에 왼손 윗성부 D–C–A 하강, F 베이스 유지.
- 2–5마디: D–C–D 보조음, B♭–A–G 경과음, E–D–D♭–C 연속 접근, B–C와 E♭–E 반음 접근.
- 9–12마디: Em7♭5–A7–Dm6, Dm7/C, B♭maj7–Bdim7.
- 19·22–24마디: B♭m6 위 보조음, Gm7–C7, G♭7→F6. 끝의 반음 연결과 텐션이 자연스러운지 청취 필요.

기보된 당김음·붙임줄·여백을 쓰며 자동 스윙은 없다. 모든 같은 방향 진행을 금지하지 않는다. 원 자료 선율을 복사하지 않았고 이번 반주 검색/모델 학습은 없다. Weimar 456개 성부의 음정 관찰과 이론 참고를 작곡 판단과 구별했다.

## 검증

262개 전체 테스트 통과. 두 MusicXML 왕복 확인, 두 PDF 각 1페이지 렌더·시각 검수. 화성 구간 31개의 필수 3·7음 누락 0. 첫 모티프 마디 정확 보존. 기존 자료 791,112개 성부와의 정의된 긴 음형 비교 후보 0.

외곽선 관찰에서 같은 방향 / 비교 사건 수는 저음 20/106→10/118, 최상음 21/106→13/85이다. 양손 동시 지속 길이는 72.5→84(4분음표=1). 분모·성부·음가가 바뀐 비교이며 품질 점수나 전곡 대위법 인증이 아니다. 상세 설명 문서에 한계와 근거 경로를 기록했다.

HTTP 19개 성공 및 로컬 바이트 일치, 새·이전 전달 manifest 해시 일치, 다른 네 곡 선택 기록 불변. 브라우저 샘플 재생/정지·화성 표기 전환·XML/PDF 다운로드 확인. 화면 캡처 `output/independent-jazz-preview.jpg`, 테스트 `output/independent-jazz-tests.log`, 나머지 근거 `output/independent-jazz/`에 있다. 모바일 검수는 별도 실행하지 않았다.

## 위험과 남은 판단

기존 강박 검사 경고는 2→7개다. 새 관찰은 경과 15·보조 6·반음 접근 5·미분류 2를 보고하지만 기존 경고를 제거하지 않았다. 3·13마디의 연속 접근 둘은 세 음 분류 범위 밖이다. 특정 코드/곡명 예외로 통과시키지 않았으며 실제 청취에서 연결의 설득력을 판단해야 한다.

최고·최저음 외곽선은 실제 내성의 자동 추적이 아니다. 짧은 화음의 해제와 성부별 쉼을 다르게 다루므로 비교 사건 수가 달라진다. 재즈 화성의 긴 텐션을 일괄 비화성음 오류로 취급하거나 장식음 개수를 품질 목표로 삼지 않는다. 새로운 반주 질감·반음 연결의 청취 평가는 아직 받지 않았다. 기본 적용·작곡가 스타일 자동 생성·P3/P4 재개를 뜻하지 않는다.
