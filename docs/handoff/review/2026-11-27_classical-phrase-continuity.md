# 모차르트풍 세 소품의 악구 연결판 검수 요청

[이전 종지판과 악구 연결판 전곡 비교](http://127.0.0.1:8808/classical-continuity.html). 비교판 여섯 개를 같은 피아노·템포로 듣는다. 3–8마디와 11–16마디도 선택할 수 있다.

## 자료와 방법

- Music Analysis/MusicXML/utf8의 XML 계열 3,299개 파일 중 네 작곡가의 성으로 시작하는 파일 695개를 읽었다. 피아노 이름 또는 MIDI 피아노 프로그램을 가진 양보표 단일 파트, 또는 높은·낮은음자리표로 나뉜 두 파트를 대상으로 삼았다. 관찰 가능한 두 손이 있는 정규 길이의 마디만 비교했다. 동일 관찰 시퀀스의 중복을 제거했다. 다른 파일명·판본의 같은 작품까지 완전히 식별한 작품 수는 아니다.
- 각 발음 시점의 윗보표 최고음·아랫보표 최저음을 사용했다. 붙임줄 계속음·꾸밈음은 새 발음에 포함하지 않는다. 반복·볼타 표시가 있는 마디와 불완전한 마디를 넘겨 가상의 경계를 만들지 않는다. 조성이 명시되지 않은 자리의 기능화성을 추정하지 않았다.
- 실제 이웃과 같은 곡·같은 박자의 비인접 마디를 1:1로 대응시켰다. 비인접 대조는 재현되는 주제일 수도 있다. 하나의 연결에서 오른손 음정, 직전·경계·직후 음정의 방향과 크기, 양손 외성의 동시 이동, 발음 수·발음 간격과 왼손 밀도 변화를 센다. 빈도에 5를 더해 희소한 패턴을 완화하고 실제/비인접 빈도의 로그 비를 사용한다.

| 자료 | 기여 파일 또는 악장 | 실제/대조 경계 각각 | 실제 이웃의 윗음 0–2반음 | 떨어진 마디 |
|---|---:|---:|---:|---:|
| Mozart utf8 | 59 | 5,943 | 62.4% | 24.2% |
| Beethoven utf8 | 101 | 15,389 | 55.9% | 17.8% |
| Chopin utf8 | 73 | 7,343 | 58.4% | 27.5% |
| Schumann utf8 | 1 | 427 | 53.9% | 13.8% |
| DCML Mozart Piano Sonatas train (CC BY-NC-SA 4.0) | 40 | 1,500 | 56.9% | 23.7% |

- Mozart utf8에서 두 마디의 왼손 발음 수가 같고 양쪽 모두 1–4회인 경계는 1,359/5,943, 대조는 747/5,943이다. 양손 외성이 반대 방향으로 움직인 횟수는 2,544 대 2,184였다. 인접성에는 음정 거리 이외에 반주의 연속성도 기여할 수 있다.
- DCML의 14개 작품 묶음을 하나씩 제외하고 DCML 자료만으로 점수를 다시 구했다. 같은 박자 실제 이웃이 우세한 쌍 1,182개, 비인접 우세 299개, 동점 19개. 윈도우가 겹치며 이 검사는 실제 이웃 구분 능력에 대한 것으로, 스타일 판별이나 생성물의 청취 만족도를 측정하지 않는다.

## 세 곡에 적용

기존 종지판을 출발점으로 첫 두 마디와 종지 2–3마디, 화성·템포를 보존했다. 5–6마디에 첫 두 마디의 리듬과 쉼을 현 화성에 맞게 재사용하고 13마디에 첫 마디 리듬을 회상하도록 한 것은 작곡 설계다. 그 밖의 마디는 원형, 첫음·끝음 변경, 이전 반주 리듬을 현 화성으로 옮긴 변형을 비교한다. 15개 경계의 총비용과 수정량·과도한 도약의 완만한 벌점을 동적 계획법으로 함께 계산한다. 모차르트 두 자료에는 각 3, 다른 작곡가에는 각 1의 기본 비중과 박자별 표본 보정을 사용했다. 비중은 실험 선택이며 자동 학습된 계수가 아니다. 참고 파일·원음표나 학습된 범용 스타일 모델은 배포하지 않는다.

- 햇살 아래 미뉴에트 10→11마디에서 오른손 경계가 하행 5반음에서 같은 음으로 바뀐다.
- 작은 극장의 메아리 12→13마디의 상승 9반음이 같은 음을 통한 주제 귀환으로 바뀐다.
- 정원을 도는 제비 4→5마디의 상승 10반음은 상승 2반음, 6→7마디의 하행 7반음은 하행 3반음이 된다. 도약 자체를 금지하지 않는다.

## 검증과 재현

프로젝트 Python으로 저장소 루트에서 실행한다.

```
python -m scripts.classical_bar_links "K:/Music Analysis/MusicXML/utf8" output/classical-links/model.json
python -m scripts.classical_continuity_study output/melody-studio output/classical-links/model.json
```

첫 두 마디와 종지의 음높이·쉼·길이 보존, 각 판 16마디, 피아노 오른손과 선율보 일치, 의도한 주제 리듬 재현을 MusicXML에서 확인했다. 원본·비교판은 별도 작품 ID다. 회귀 297개 중 295개 통과. 기존 XML 마디 번호 출력 바이트 및 프레이즈 경계 기대값 테스트가 실패했다. 실험판에만 반영했고 자연스러운 연결에 대한 최종 판단은 청취 검수 대상이다.
