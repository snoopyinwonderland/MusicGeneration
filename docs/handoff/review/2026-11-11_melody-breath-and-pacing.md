사용자 원문: “만든 음악들의 멜로디가 너무 일정한 호흡으로 이루어지는 것 같습니다. 당겼다 풀었다 하는 완급 조절이 있으면 좋겠습니다. 긴 음표, 긴 쉼표가 안 보이네요. 짧은 음표로 휘몰아치다가 늦추고, 천천히 가다가 빨라지고, 이런 것들도 필요하겠죠.”

다섯 곡의 작성본 v004를 보존하고 v005에 긴 지속·쉼, 16분음표 움직임, 늦은 진입을 썼다. 전달본은 기존 요청별 v001을 유지하고 v002를 추가했다. 실제 사용자 의견을 수정 근거에 기록했으며 `author_demo` 요청을 사용자 선택으로 바꾸지 않았다. 작성 데이터와 음표는 Git 제외 `output/`에만 있다.

- `musigen/melody_pacing.py`: `gaps`, `observe`. 겹친 기보 음 구간의 여백과 마디별 발음·지속·쉼 관찰. 붙임줄은 호출자가 먼저 합친다. 자동 분절·반복 감점·품질 점수·생성기 연결 없음.
- `tests/test_melody_pacing.py`: 붙임줄 지속을 쉼으로 세지 않음, 겹치는 성부/앞뒤 쉼, 범위 오류를 검사.
- `docs/MELODY_BREATH_AND_PACING.md`: 수정 의도·자료 활용 범위·수치·한계·향후 작성 절차.
