## 무엇을 왜 바꿨나

사용자가 기존 곡에 “한결 낫네요”라고 평가한 뒤, 같은 주선율·화성에서 반주 리듬과 내성·음량 균형을 개선하는 제안을 승인했다. A의 121개 주선율 음, 39개 화성 구간, 조성·박자·빠르기·기보 셈여림·헤어핀·페달을 보존했다. 왼손 23마디를 지속 베이스와 별도 내성, 펼침화음으로 다시 썼다. 9–12·17–20마디의 기존 lyrical 반주와 32마디 종결은 유지했다.

## 추적 파일·함수

- `musigen/piece.py`: `Piece.playback_balance`, `build`에서 선택 계획 검증·보존.
- `musigen/expression.py`: `compile_balance`, `playback`의 선택 음량 정보. 범위·겹침·값 검사, 기존 페이로드는 계획 없을 때 유지.
- `musigen/listen_template.html`: `applyPerformance`의 피아노 손별 배수·동시 LH 발음 완화, `about`의 적용 안내. 재생과 WAV 모두 기존 최종 level 경로 사용. 음표 시각·길이·XML 불변.
- `tests/test_playback_balance.py`: 기존 XML 불변, 여린내기/인접 구간, 잘못된 계획 거절.
- `tests/test_studio_delivery.py`: 실제 전달 페이지에 계획이 남고 XML이 보존되는 통합 시험 추가.
- `tests/playback_balance.test.mjs`: 실제 플레이어 함수 실행으로 기본값·중립·손/악기·경계·동시음·시각/길이 확인.
- 설명 문서, README, 작곡 지침, 계획 상태, 이 검수 요청서.

작품 음표와 제작 스크립트는 Git 제외 `output/count-on-me/`에 있다. musicomp를 새로 수정·학습·검색하지 않았으며 이전 lyrical 결과의 일부를 유지했다. 일반 코드에는 작품 이름에 따른 예외가 없다.

## 전후와 들어 볼 곳

A: 작성 v003 / 전달 v001. B: 작성 v005 / 전달 v002. 「바뀐 곳 비교」로 1–4, 5–8, 13–16, 29–32마디를 각각 A→B 순서로 들을 수 있다.

- 1–8: 기존의 반복적인 왼손 발음에서 지속음·시차 응답으로 변경. A–Ab와 F–E 내성.
- 13–16: 펼침화음으로 흐름을 더함.
- 21–31: 공통음·반음 연결과 종결의 시차 진입.
- 재생: 선택 구간별 RH/LH 배수와 동시 LH 발음 완화. 악보의 셈여림은 그대로다.

마디별 새 발음 시각 패턴은 9→15종, 가장 반복적이던 패턴은 20/32→4/32마디다. 음악적 품질 점수는 아니다. 이번 B에서 반주와 재생 균형은 함께 바뀌었다.

## 검증

- Python `unittest discover -s tests`: 266개 통과. Node `tests/playback_balance.test.mjs` 통과.
- 주선율·화성 등 통제 조건 정확 일치. 두 XML 재읽기 일치, 공통 화성 XML/PDF 바이트 일치.
- 명시적 내성 17/17 연결 확인. 실제 LH 음높이 사건 209개 중 23개를 지정했고, 하나의 연결은 의도한 반 박 쉼이 있다.
- 실제 지속음을 포함한 LH 폭 최대 12반음, 양손 교차 0. 소리 나는 38개 화성의 3·7음 누락 0. 첫 마디의 5음 G 생략과 24마디 후반 G7의 양손 쉼은 기록했다.
- 솔로 오류 0, 경고 7. 기존 6개에 2박 쉼을 넘긴 8→9 병행 8도 경고가 추가됐다. 쉼을 끊어 보는 외곽선 관찰의 병행 완전음정은 0/0. 모든 내성을 판정하는 검사는 아니다.
- 새 솔로 PDF 1쪽 시각 확인. 실제 A→B 전환·정지 및 XML/PDF/WAV 다운로드 확인, 브라우저 오류 0. HTTP 25개 대조. 이전 전달 18개 파일 해시와 기본 예제 XML 해시 보존.
- WAV 44.1kHz/모노, 91.929초, 비무음, 포화 샘플 0. 청취 품질 보증은 아니다.

## 위험·한계

1. 음량 배수와 `1/√N` 완화는 작성한 청취용 설정이다. 실제 피아노 터치·음향 보정이나 새 학습 모델이 아니다. 계획 없는 곡의 음량은 기존 그대로다.
2. 동시 새 발음만 세며 이미 유지 중인 음은 세지 않는다. 전체 음향 밀도를 추정하지 않는다. 0 배수는 해당 손의 명시적 무음이다.
3. 이번 결과의 사용자 청취 승인과 main 병합은 별도다. 이전 “한결 낫네요”를 B의 승인으로 기록하지 않았다.
4. 주선율의 추가 변형·세컨더리 표기 개선·루바토는 이번에 구현하지 않았다. 승인한 다음 비교판의 통제 조건을 유지했다.
