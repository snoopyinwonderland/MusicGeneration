# 검수 요청 · 막차 전 한 잔

`codex/jazz-corpus-piano-study`에서 사용자 요청에 따라 재즈 선율 학습과 피아노 작곡을 시험했다. [작품과 악보](http://127.0.0.1:8808/last-train-jazz.html) · [선율만 듣기](http://127.0.0.1:8808/listen/last_train_jazz/v001/melody_only.html) · [피아노 솔로](http://127.0.0.1:8808/listen/last_train_jazz/v001/piano_solo.html)

## 학습과 자료의 역할

`musigen/jazz_corpus.py`의 `fit`은 로컬 코퍼스에서 빈도와 조건부 확률을 계산한다. `wjd`는 Weimar의 4/4 스윙 솔로를 작품 ID별로 분리하고 직전 음정과 박 위치에 따른 다음 음정, 화음 근음에 대한 상대 음급을 학습한다. 183작품 278솔로의 전이 125,075건을 학습했고, 다른 42작품 69솔로의 전이 29,670건에서 확인했다. 다음 음정의 평균 음의 로그 가능도는 전체 빈도 기준 2.517에서 조건부 모델 2.398로 줄었다. 음정 예측 지표이며 선율의 음악적 품질을 평가한 값은 아니다.

| 자료 | 실제로 사용한 범위 |
|---|---|
| Weimar | SQLite 솔로와 박·화음 표에서 확률 계산. IDEA 릭은 가져다 붙이지 않았다. |
| Parker Omnibook | XML 400개를 파일명 계열 50개로 묶어 첫 정렬 판본만 사용. 전사 판본에서 세어 얻은 음정 분포를 선율 후보 점수에 7%로 섞었다. |
| JazzNet | 메타데이터 162,520행의 합성 연습 패턴을 확인했다. 장·단조 ii–V, 턴어라운드와 트라이톤 대리의 형식을 화성 설계에 참고했다. MIDI 압축본을 학습에 넣는 단계는 별도다. |
| FiloBass | XML 193개를 파일명 계열 49개로 묶어 마디 경계 12,783건을 집계했다. 다음 베이스에 접근하는 음의 후보를 고르는 데 사용했다. |
| PiJAMA | train에서 경로를 찾은 아티스트 24명의 MIDI 한 곡씩을 읽었다. 같은 틱에 울리는 다중 발음 3,230건 중 두 음이 2,946건이어서 두 음 컴핑을 우선했다. 녹음 전체를 대표하는 표본이나 스윙 타이밍 분석은 아니다. |
| RealBook / Jazz Harmony Treebank | RealBook 135개 파일명 계열에서 화성 표기 수가 마디당 1–2개인 경우는 3,608/4,153마디였다. 시험곡의 화성 변화 밀도에 참고했다. Treebank 1,170레코드는 목록을 확인했다. |

통계는 `python -m musigen.jazz_corpus --root 'K:/MusicSearch/data/jazz-corpora' --out output/jazz-corpus-study/fit.json`으로 재현한다. 원자료와 결과 파일은 Git 제외 폴더에 있다.

## 마디 단위 작곡과 청취

F장조 32마디 AABA, ♩120의 피아노 솔로다. 먼저 주제, 리듬, 쉼과 구절별 도착음을 작성했다. `rank_bar`는 9–12·17–24마디에서 후보를 최대 24개씩 남기고, 앞 마디의 끝음을 음정 문맥으로 사용하며 다음 마디 시작음까지의 거리도 점수에 넣는다. 이 중 20마디는 작성한 긴 음 한 개이고, 나머지 11개 마디에서는 모델이 중간 음을 선택했다. 왼손은 화음의 3음과 7음을 중심으로 엇박 컴핑을 배치하고 일부 마디에서 워킹 베이스를 쓴다.

- 1–8마디에서 선율만으로 엇박의 주제와 긴 응답이 들리는지 확인한다.
- 9–16마디에서 마디별 모델을 쓴 연결과 16마디 후반의 쉼을 비교한다.
- 17–24마디에서 음역과 밀도의 대비를, 25–32마디에서 주제 귀환과 종지를 듣는다.

초안의 선율에는 Weimar와 이조해도 같은 10음 음정열 두 곳이 있었다. 29마디 이후의 연결을 고치고 11마디에서는 모델의 두 번째 후보를 골랐다. 최종 148개 음정열을 Weimar 456솔로와 Parker 50개 전사에 대조했으며 일치 0개다. 이 검사는 열 음의 음정열에 한정된다.

## 결과 검증

코드는 `musigen/jazz_corpus.py`, 곡 작성·발행은 Git 제외 `output/jazz-corpus-study/compose.py`, `publish.py`에 있다. 로컬 초안 v001은 초회 계산이며 완성한 v002를 감상판 v001로 제공한다. 두 악보 XML을 다시 읽어 선율 157개 발음과 41개 화성 구간을 확인했다. 피아노 솔로에서 양손 외곽선 병행 완전음정 0, 두 악보 오류 0이다. 26마디 D7 위 E–E♭–D의 반음 접근은 강박 비화성음 경고 1개로 남는다.

PDF 각 2쪽을 렌더링하고 브라우저에서 왼손이 꺼진 선율 단독 재생과 양손 피아노 샘플 재생을 확인했다. MusicXML·PDF·WAV 다운로드를 검증했고, 44.1kHz 모노 WAV는 63.925초이며 포화 샘플 0개다. HTTP 23개 자원 해시 대조 및 Python 테스트 266개가 통과했다.
