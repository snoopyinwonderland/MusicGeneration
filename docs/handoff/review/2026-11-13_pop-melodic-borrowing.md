## 변경과 선택 근거

- `musigen/melodic_borrowing.py`의 `motifs_from_chart`는 검증한 차트 자료에서 4음 817개, 5음 1,026개, 6음 1,098개의 연속 모티프를 확보했다. 긴 쉼을 가로지르는 후보와 음높이 종류가 셋 미만인 후보를 제외했다.
- `fit_options`는 같은 위치의 리듬을 가져온 곡과 다른 곡에서 음정을 고른다. 원곡의 상대 음정을 유지하도록 전체 이조하고, 기존 리듬의 정규화된 시작 간격과 음값이 원구간 리듬과 모두 같은 경우를 제외했다. 모티프마다 절반 이상의 음높이가 기준판과 달라야 한다. 코드와 강세, 음역, 주변 음과의 이동에 비용을 부여했다.
- `arrange_borrowings`와 `compare_versions`는 모티프가 서로 겹치지 않도록 배치하고 목표 음수에 가까운 경로를 찾는다. 한 출처에서 최대 두 모티프를 사용하고 같은 출처가 연속으로 나오지 않게 했다. 모티프 범위와 실제 음높이 변경 수를 각각 표시한다. 각 판은 기준판에서 독립적으로 선택한다.
- 10%판은 13–14마디에서 Birds of a Feather의 6음 모티프를 쓴다. 50%판은 4, 7, 9, 11–14마디에 모티프를 배치했다. 90%판은 12곡에서 가져오며 16마디의 Cadd9 위 B음에 자동 검사 주의가 한 건 남는다.
- 로컬 출력 `output/pop-melodic-borrowing`의 `report.json`에 곡 ID, 원자료 위치, 출력 마디, 상대 음정과 적용 음수를 기록했다. 비교 악보와 출처 자료는 Git 제외 폴더에 있다.

## 확인 결과

- 다섯 판의 오른손 시작 시점과 길이 및 왼손 전체가 기준판과 동일하다. MusicXML을 다시 읽어 양손의 시점·길이·보표·음높이를 대조했다.
- 차용 구간마다 원자료와의 상대 음정 일치, 리듬의 차이, 4–6음 길이, 비중의 합계를 확인했다. 791,085개 성부에 대한 연속 12음 일치·16음 근접 일치가 다섯 판 모두 0건이었다. 청취상 유사성과 권리 판단은 이 수치의 범위를 벗어난다.
- 브라우저에서 기준판과 다섯 판의 선택 전환 및 피아노 재생을 확인했다. 각 PDF는 한 페이지로 출력해 확인했다. 전체 테스트 273개 통과.
