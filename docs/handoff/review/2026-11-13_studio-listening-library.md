# 8808 작품 라이브러리 검수 요청

브랜치 `codex/studio-listening-library` · 기준 `d580e56`. [8808 첫 화면](http://127.0.0.1:8808/)에 작품 라이브러리를 배치했다. 이전에는 모티프 입력 화면에서 시작했고 곡마다 별도 주소를 열어야 했다. 첫 화면에서 작품 제목을 누르면 대표 청취판을 열고, 수정판·비교판·상세 화성이 있는 경우 바로 아래 링크에서 선택할 수 있다. 제목과 편성으로 검색하며, ‘모티프 입력’은 같은 페이지의 기존 입력 화면으로 이동한다.

- `musigen/studio_library.py`의 `library_html`은 출력 폴더의 `library.json`을 읽어 첫 화면에 링크를 작성한다. 실제 파일이 있는 로컬 주소를 사용하며 곡명과 설명을 HTML 이스케이프한다.
- `musigen/studio.py`의 `write_studio`, `studio.html`, `studio.css`, `studio.js`에 선택 라이브러리와 검색을 연결했다. 일반 스튜디오는 `library.json` 없이도 열 수 있다.
- 현재 목록은 8808에 있던 청취판과 다른 로컬 작업 폴더에서 복사한 초기 작품·실험판을 포함한다. 39개 항목, 대표 및 관련 링크 73개다. 목록과 복사본은 Git 제외 `output/melody-studio`에 있고, 작성 스크립트는 `output/build_listening_library.py`에 있다. 작업 폴더에 남아 있는 청취판을 기준으로 작성했으며 새 곡을 추가할 때 목록을 갱신한다.
- 첫 화면과 목록의 73개 링크가 HTTP로 열리는 것을 확인했다. 브라우저에서 「겨울 아침」 검색·피아노 재생과 「창가에 켜진 불」의 최신 비율 메뉴, 검색 결과 없음 표시를 확인했다. 기존 일부 비교판의 부속 제작 자료 링크는 원본 폴더에서도 파일이 빠져 있다. 음악 청취 링크는 목록에서 열린다.
- `tests/test_studio.py`에서 출력 폴더 내 악보 링크, 버전 주소, 제목 이스케이프와 사라진 항목 처리를 검증한다.
