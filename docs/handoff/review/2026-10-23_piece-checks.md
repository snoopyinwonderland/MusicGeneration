# P3 음악 검사 검수 요청

브랜치 `codex/piece-checks`, P2 `9237695`에서 시작.

`musical_checks.evaluate`: 강박 비화성음·해결형, 외성 병행, 반복 리듬, 구간 통계/대조, 종지 의도 검사. `checks.check`와 듣기 페이지에서 오류/주의/참고를 구분합니다. `design.validate`에 cadence 값 검증을 추가했습니다. `piece.build`는 화음 기호를 숨겨도 분석용 화음을 보존합니다. 직접 쓴 블록에 화음 기호가 없으면 이전 화음을 억지로 적용하지 않고 미평가 참고를 냅니다.

테스트 42→49개. 새 검사의 양성·예외·계류·전타·경과·9도·복사/seq·종지 네 종류·대조·기호 숨김을 검증. 기존 검사 결과는 유지하며, 기존 테스트의 경고 기대값은 새 음악 검사만 별도로 확인하도록 분리했습니다. after_rain XML 바이트 회귀 유지.
