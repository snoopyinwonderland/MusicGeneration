# 작곡 조성 및 편곡 악보 화면 검수 요청

- 브랜치 `codex/all-keys-score-layout`. 이전 MOTIFIND 편곡 작업대 브랜치에서 이어서 작업했다.
- 작곡 작업실과 요청 보관 화면에서 고를 수 있던 11개 조성을 30개로 늘렸다. `musigen/key_signatures.json`을 서버의 입력 검사, 두 HTML 화면과 입력기 두 악보 보기의 공통 기준으로 사용한다. 기본 선택은 C장조다.
- `editor/arranger.mjs`의 편곡 작업대에서 상단 설정과 악보가 정해진 창 높이를 나누어 쓰던 레이아웃을 문서 스크롤로 바꿨다. 좁은 창에서는 분석 패널이 악보 아래에 놓인다. `musigen/workshop.css`에서 바깥 프레임 높이를 화면의 95%로 설정했다.
- 검수 경로는 [8마디 편곡 작업대](http://127.0.0.1:8808/compose.html?piece=360b156a67e8413aaf05b61f0cba1175&workspace=arranger)다. 저장된 편곡에서 ‘새 곡 닫기’를 누르고 1–8마디를 확인한다. Edge 1280×760에서 악보 3단, 높이 2,499px, 내부 악보 잘림 0px를 확인했다.
- 30개 조성으로 8마디씩 실제 생성해 선율·화성 두 파트의 MusicXML fifths와 mode를 검사했다. 기본 적용 범위는 입력 조성과 화면 배치다. 기존 곡의 청취 품질은 이번 검수 대상에서 제외했다.
- Python 회귀 292개 중 291개 통과. 이전 검수 때와 같이 프레이즈 경계 테스트 한 건에서 실제 4구간과 기대 6구간이 다르다. 입력기 번들은 로컬 편곡기 설치의 Vite 및 입력기 배포 파일을 사용해 다시 빌드했다.
