# 가사·악보 탐지 기준표 검수

- [작품 표](http://127.0.0.1:8808/longing-pair.html#detection)에서 1마디 네 음과 1–2·7–8마디 화음 쌍의 조건, 검출 수, 분모, 비율을 확인한다. 박자·음·재생 범위는 이전 후보를 따른다.
- [전체 통계](http://127.0.0.1:8808/karaoke-lyric-associations.html#detection)에서 여섯 단서의 한글·영어 표현, 문자권별 검출 줄 수 및 여섯 악보 특징의 예시를 확인한다. 한글 사이 공백, 복수 검출, 부정어 한계를 명시했다.
- 가사 사전을 `scripts/karaoke_lyric_cues.json`으로 옮겨 분석기와 통계 페이지가 함께 사용한다. 기존 여섯 규칙과 단어 목록을 대조했다. 이전 전수 집계 JSON으로 두 표를 생성했으며 원본 MIDI 재집계는 수행하지 않았다.
- Edge에서 작품 3행 및 전체 표 두 개의 각 6행과 실제 링크·분모를 확인했다. Python 회귀 294/295 통과, 기존 프레이즈 경계 기대값 실패 1건. 검수 브랜치 `codex/detection-tables`.
