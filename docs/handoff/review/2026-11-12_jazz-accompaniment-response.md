사용자는 재생이 끊겨 들릴 수 있고 양손이 따로 움직이는 느낌이라며 왼손 화음 패턴에 변형을 요청했다. 오른손의 음과 시각, 쉼, 41개 화성 구간과 빠르기를 기준으로 왼손 1–31마디를 다시 썼다. 32마디의 종결은 이전과 같은 기보다. 왼손 화음 성부의 마디 내 발음 위치 조합은 6종에서 19종으로 늘었다. 초기판의 최다 조합은 14/32마디였고 수정판의 최다 조합은 6/32마디다. 이는 리듬 배치의 관찰값이다.

## 듣기 비교

- 1–8마디에서 베이스와 한 음씩 쌓이는 내성, 4마디의 길게 머무는 선율에 들어오는 화음을 듣는다. 8마디의 오른손 픽업 앞에는 왼손이 물러난다.
- 16마디의 오른손 쉼에서 왼손이 짧게 응답한 뒤 양손이 한 박 쉰다. 17마디는 Am7♭5의 감5음을 실제 왼손에 넣었다.
- 20마디는 길게 머무는 선율 뒤로 화음이 늦게 들어오고, 26마디의 빠른 선율 시작은 베이스가 받친다. 28마디의 내성은 한 음씩 움직여 화음에 모인다.

## 스윙 재생 시간표

기존 스윙은 엇박에서 시작하는 음은 늦췄지만, 앞에서 시작해 같은 엇박에 끝나는 음은 특정 길이에서만 늘렸다. 같은 박 위치에서 음을 교대해도 발음과 끝 시각이 맞지 않을 수 있었다. 원본 시험곡의 Verovio 시간표와 MIDI 길이가 일치한 사건 427개를 대조하니 7개 종료 지점이 기존 엇박 시간과 어긋났고, 최대 차이는 ♩120에서 약 83ms였다. 수정 기보에 두 방식의 수식을 대입한 344개 비교 사건에서는 이전 방식의 어긋남 17개와 선택 방식의 어긋남 0개를 확인했다. 음원의 감쇠 및 아티큘레이션을 적용하기 전 시간표 비교다.

`musigen/design.py`에서 `basics.swing: true`와 함께 `swing_timing: "shared_grid"`를 지정할 수 있다. `musigen/listen_template.html`의 `sharedSwingGrid`는 양손의 시작과 종료를 같은 엇박 이동으로 처리한다. 16분음표나 셋잇단음표처럼 더 세분된 사건이 있는 박은 양손 모두 기보 비율대로 둔다. 기존 방식도 같은 선택 경로에서 사용할 수 있다. 이 확인으로 청취 기기의 버퍼 문제 여부까지 판정할 수는 없다.

## 파일과 검증

- 변경 코드는 위 두 파일과 `tests/swing_grid.test.mjs`다. 곡별 편곡 및 발행 스크립트는 Git 제외 `output/jazz-corpus-study/revise_accompaniment.py`, `publish_accompaniment.py`에 있다. 작성 v004를 감상 v002로 제공한다.

- Python 266개, Node 스윙 2개와 기존 음량 균형 검사를 통과했다. 새 솔로 PDF 2쪽을 렌더링했다. 브라우저 피아노 샘플 재생과 WAV·PDF·MusicXML 다운로드를 확인했고 다운로드 악보와 작성본이 일치했다. WAV 44.1kHz 모노, 63.925초, 포화 0개와 HTTP 22개 해시를 확인했다.
