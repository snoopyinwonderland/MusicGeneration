사용자 의견은 “조금 좋아지긴 했습니다. 오른손 주선율에도 모차르트 스타일의 변형을 좀 주면 좋겠는데요.”였다. 전체 88마디 편곡의 첫 주제 제시를 살리고, 두 번째 응답과 후반 재현에 이웃음, 짧은 상·하행과 종지 장식을 넣었다. 기존 오른손 289개 발음은 음높이와 시작 시각을 모두 보존했다. 그중 13개의 음가를 짧게 나누면서 오른손 발음 34개를 추가했다. 47–49마디의 셋잇단음표와 84–86마디의 붙임줄은 기존 기보를 사용했다.

모차르트 K.265 주제와 제1변주 첫 구절의 이웃음 왕복은 기존 관찰에서 0/14개와 10/49개였다. K.25의 첫 구절 변주에서는 주제의 발음 시각 27개가 모두 공유되고 24개에서 음고류가 같았다. 이 두 사례를 참고해 곡의 주요 음과 발음 시각을 남겨 두고 그 사이를 장식했다. 원곡 음열, 구절의 길이, 발음 밀도를 참조곡에 맞춰 복제하는 방식은 사용하지 않았다. 기존 관찰의 작품 ID와 자료 경로·해시는 이번 결과의 `result.json`에 기록했다.

## 산출물과 확인 범위

- Git 제외 `output/always-with-me-mozart/ornament.py`의 `replace_treble`이 고정한 기보에서 선택한 음을 분할한다. `publish.py`가 새 버전과 이전 버전 링크를 제공한다. 소스 변경은 이 검수 요청서다.
- 악보를 다시 읽어 기존 289개 오른손 발음의 음높이·시각, 추가 34개 발음과 바뀐 13마디를 대조했다. 왼손 음표와 쉼표는 두 악보 모두 기존 XML과 같다. 피아노 솔로 외성 병행 완전음정 관찰은 0이다.
- 기존 경고에 83마디 강박 비화성음 D 한 건이 추가됐다. 턴의 첫 음이며 곧바로 C♯으로 해결한다. 상세 화성판은 블록 화음의 기존 병행 경고 4개도 유지한다. 자동 검사 오류는 두 악보 모두 0이다.
- 두 PDF 각 4쪽을 렌더링해 확인했다. 피아노 샘플 재생, MusicXML·PDF·WAV 다운로드를 확인했다. 내려받은 XML/PDF는 작성본과 일치하고, WAV는 22.05kHz 모노·146.054초·포화 샘플 0이다. 로컬 HTTP 14개 자원을 해시로 대조했고 Python 테스트 266개가 통과했다.
