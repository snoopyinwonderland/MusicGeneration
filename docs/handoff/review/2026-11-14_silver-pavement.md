# 「은빛 골목」 피아노 솔로 검수 요청

브랜치 `codex/after-the-rain-walk` · 기준 `5f0aab1`. 이전 작업에서 다룬 짧은 음형 차용을 새 곡에 적용했다. G장조 4/4, ♩=96, 20마디, 약 50초다. 왼손을 직접 쓰고 8급 설정으로 악보를 검사했다. 페달은 쓰지 않았다. [은빛 골목 v003](http://127.0.0.1:8808/listen/silver-pavement/v003/index.html#piece=silver_pavement&version=v003)

`output/after-the-rain-walk/`에 출처 검색 `cells.py`, 작곡과 MusicXML 출력 `create.py`, 감상 페이지 및 작품 목록 갱신 `publish.py`가 있다. 세 음의 절대 음높이를 이조 없이 사용했고, 리듬은 새 프레이즈에 맞게 썼다. 선율의 72개 음 시작 가운데 12개에 해당한다. 원자료 파일과 성부, 위치는 같은 폴더의 `report.json`에 있다. 악보와 실행 자료는 로컬 `output/`에 두었다.

이전 「조용한 귀갓길」과 비교할 때 첫 주제와 13마디의 리듬 변형, 4·8·16마디의 한 박짜리 양손 쉼, 9–12마디의 절정과 G7–C/E 전환을 들어 보면 된다. 19–20마디의 왼손 저음 D와 G는 각각 네 박이며 마지막 안쪽 화음은 저음보다 한 박 뒤에 들어온다. [이전 곡 감상](http://127.0.0.1:8808/listen/quiet-road/melody-detail/index.html#piece=quiet_road_melody&version=v002)

MusicXML을 다시 읽어 129개 음표의 시점, 길이, 음높이, 보표와 성부를 대조했다. 악보 검사 오류·주의는 0건, 단위 테스트 274개는 모두 통과했다. PDF 한 페이지를 확인했고, 감상 페이지에서 피아노 샘플 재생 시작과 MusicXML·PDF·WAV 버튼 표시를 확인했다. 8808 홈에 작품을 추가했다. [8808 작품 목록](http://127.0.0.1:8808/#library)

색인에 있는 791,135개 성부를 대상으로 두 마디 이상에 걸친 연속 12음 일치와 16음 근접 일치를 검사했고 해당 구간은 0건이었다. 검사는 색인과 지정한 길이에 한정된다. 프레이즈의 호흡과 종지의 인상은 청취 검수 대상이다.
