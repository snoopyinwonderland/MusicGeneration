# 「한 걸음 늦게」 2차 청취 검수 요청

- 브랜치 `codex/one-step-late-phrase-revision` · 기준 `1ce141b` · 작업 트리 `K:/MusicGeneration/melody-research`
- 사용자 의견 “한 걸음 늦게의 5~8번째 마디는 조금 괜찮은 편이고 나머지는 아직도 좀 별로입니다. 2분음표 뒤에 2분음표 나오는 건 노래하기에 좋은 리듬으로 들리지 않습니다. 그렇다고 이걸 금지하는 룰을 만들라는 것은 아닙니다.”
- [새 청취판](http://127.0.0.1:8808/listen/phrase-first/v002/one_step_late.html#piece=one_step_late&version=v002)의 **1–8마디 비교 듣기**에서 [이전판](http://127.0.0.1:8808/listen/phrase-first/v001/one_step_late.html)과 새 판을 차례로 들을 수 있다. 각 버전의 MusicXML·PDF는 청취판에서 받는다.

## 악보 변경

| 구간 | 새 청취판 |
| --- | --- |
| 1–4마디 | 첫 G의 반복 뒤 조금씩 올라간다. 2마디 끝 A를 3마디로 이어 강박을 지나고, 4마디 끝에서 한 박 쉰다. |
| 5–8마디 | 음높이·시작 시점·길이가 이전판과 같다. 6마디에서 E♭에 머물고, 7마디 반 박 쉼 뒤 짧은 음들을 거쳐 8마디 G에서 숨을 고른다. |
| 9–14마디 | 한 박 쉰 뒤 움직인다. 9–10마디 D를 이어 음을 다시 치지 않고, 11마디 F에서 점4분음표만큼 머문 뒤 짧게 풀어낸다. |
| 15–20마디 | 첫 반복음의 리듬을 되살리고 끝의 음정을 바꾼다. 마지막 G는 19마디 끝에서 시작해 20마디까지 이어진다. |

G단조, 3/4, ♩=108, 20마디의 피아노 단선율이다. 2분음표는 5–8마디의 두 음과 마지막 G에 남아 있다. 새 문장은 긴 음의 앞뒤에 어떤 음과 쉼이 오는지 보고 작성했다. 이번 패키지는 악보 편집과 로컬 청취판에만 적용되며 생성기 규칙 변경은 없다.

## 검증과 범위

- 작업 파일 `output/one-step-late-v002/compose_revision.py`에서 기존 작곡 스크립트의 `make`로 MusicXML을 출력한다. XML을 다시 읽어 음높이·시작 시점·길이를 대조했고, 5–8마디의 10개 음 사건이 모두 같음을 확인했다. `publish_revision.py`는 `musigen.listen._write_page`를 사용해 두 판을 묶는다. 두 스크립트와 악보는 Git 제외 `output/one-step-late-v002`에 있다.
- 선율 DB와 이전 출력 DB의 791,135개 성부를 대조한 연속 12음 일치·16음 근접 일치가 0건이었다. 이전 작품 50개 및 1차의 다른 두 후보와 연속 8음 일치도 0건이다. 같은 곡의 이전판에서 의도적으로 보존한 5–8마디에는 연속 8음 일치 창이 3개 있다. 이 검사는 이조·균일한 빠르기 변화를 보정한 기보 비교에 해당한다.
- PDF 한 페이지를 시각 확인했다. 새 청취판의 비교 버튼이 이전판 1–8마디에서 새 판의 같은 구간으로 이어지는 동작을 브라우저에서 확인했다. 청취판, XML, PDF, 피아노 샘플이 HTTP로 제공된다.
- `python -m unittest discover -s tests` 266개 통과. 새 선율에 대한 사용자의 청취 평가는 후속 검수에 남아 있다.
