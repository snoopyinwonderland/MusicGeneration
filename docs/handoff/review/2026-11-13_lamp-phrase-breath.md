# 「창가에 켜진 불」 프레이즈 수정 검수 요청

브랜치 `codex/lamp-phrase-breath` · 기준 `aa35ba2`. 사용자 의견은 “이번 노래는 좀 별로네요. 호흡, 프레이즈가 잘 느껴지지 않았습니다.”였다.

[수정판 v006](http://127.0.0.1:8808/listen/lamp-in-the-window/v006/index.html#piece=lamp_in_the_window&version=v006)에서 **5–12마디 전후 듣기**를 누르면 이전판 v003과 수정판을 차례로 재생한다. 상단에서 전체 판을 바꿔 들을 수 있다. 양쪽 버전의 MusicXML, PDF와 피아노 샘플 WAV를 받을 수 있다.

| 구간 | 수정한 악구 |
| --- | --- |
| 1–4마디 | 반 박 뒤 E–G–A로 들어와 2마디 D에 닿고, 4마디의 낮은 E로 끝낸다. |
| 5–8마디 | 첫 리듬을 바탕으로 5마디의 끝음을 바꾼다. 6마디의 짧은 모티프를 7마디의 긴 C와 8마디 G로 이어 준다. 양손 사이 공백을 한 박 반 둔다. |
| 9–12마디 | 오른손을 한 박 늦게 넣는다. 11–12마디의 F를 마디 너머까지 붙임줄로 이어 가장 높은 곳에서 머문 뒤 E로 내려오고, 양손이 반 박 쉰다. |
| 13–16마디 | 높은 곳에서 내려온 뒤 15마디에 E–G–A를 압축해 되돌린다. G7 뒤 오른손 C와 왼손 C 화음을 세 박 유지하고 한 박 쉰다. |

양손을 동시에 놓는 시간은 4·8·12·16마디 끝에서 기존 1·0·0·0박, 수정 후 1·1.5·0.5·1박이다. 악구별 이음줄과 셈여림 증감을 악보에 적었다. 기존에 차용한 모티프 중 6마디의 Birds of a Feather, 10마디의 남자를 몰라, 11마디의 My Love (And) 상대 음정을 유지하고, 나머지 선율은 호흡과 도착음에 맞춰 다시 썼다.

악보 입력과 검증은 Git 제외 `output/melody-led-harmony/phrase_revision.py`에 있다. `joint_space`가 양손 공백을 계측하고, `publish_phrase_revision.py`가 기존 `musigen.listen._write_page`로 두 판을 제공한다. 자동 프레이즈 관찰에는 기존 `musigen.phrases.analyze`를 썼다.

자동 프레이즈 관찰은 4·8·12·16마디를 끝으로 찾았다. 음표 이벤트 95개의 보표, 음높이, 시점과 길이가 MusicXML 재읽기와 일치했다. 악보 검사 오류·주의 0건. 왼손 연결에는 7→8, 8→9, 12→13마디 도약 참고가 남아 있다. PDF 한 페이지와 브라우저에서 5–12마디 이전판→수정판의 피아노 재생을 확인했다. 791,135개 성부의 연속 12음 일치와 16음 근접 일치는 0건이었다. 전체 테스트 273개 통과. 프레이즈가 실제로 더 또렷하게 들리는지는 청취 비교로 검수한다.
