# 조성과 악보 표기 선택 검수 요청

- 브랜치 `codex/key-spelling-picker`. 작곡 작업실과 작곡 요청 화면의 조성 메뉴를 기존 30행에서 장조 12행과 단조 12행으로 변경했다.
- `studio.py`의 `key_picker_options`가 같은 선법 안에서 5도권 위치가 12칸 차이 나는 조성을 묶는다. `key_picker.js`가 여섯 이명동음 쌍에만 표기 선택을 보인다. 기본값은 조표가 적은 쪽이고 동률은 샵 쪽이다.
- `studio.html/js`, `workshop.html/js`에서 입력기, 생성 요청, 요청 JSON, 저장 곡 재열기에 같은 표기 값을 사용한다. 기존 파일 형식과 서버의 30개 표기 값은 그대로 사용한다.
- [작곡 화면](http://127.0.0.1:8808/compose.html)에서 B / C♭ 장조를 고르고 악보 표기를 바꿔 확인한다. Edge에서 두 화면의 12+12개 항목과 표기 30개 전체, 단일 표기 숨김, 기존 곡 응답을 C♭장조로 대입한 복원, 표기를 바꾼 후 자동 모티프 요청 값을 확인했다.
- 기본 적용한 UI 변경이다. 이번 변경에는 청취 비교 대상이 없다. Python 회귀 테스트 292개 중 291개 통과. 기존 프레이즈 경계 테스트는 4구간과 기대값 6구간 차이로 실패한다.
