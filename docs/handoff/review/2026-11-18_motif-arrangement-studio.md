# 작곡 작업실 검수 요청

브랜치 `codex/motif-arrangement-studio` · 기준 `9c225b6` · [로컬 작업실](http://127.0.0.1:8808/compose.html)

## 입력부터 편곡까지

- 음표 버튼, 음이름·음가 텍스트, 모티프 JSON을 입력할 수 있다. 기존 스튜디오에서 MusicXML을 연 뒤 성부·처음 음·끝 음을 선택하고 ‘이 모티프로 바로 작곡’을 누르면 선택 구간이 넘어온다.
- 자동 생성은 두 마디를 새로 만든다. 이어쓰기는 입력한 음높이·음가·쉼을 보존하고 두 마디까지 채운다. 완성된 모티프의 음높이·길이도 화면에서 수정할 수 있다. 직접 입력 후 바로 작곡할 수 있고, 8·16마디 중 선택한다. 한 마디보다 짧은 시작은 발전에 쓸 재료를 먼저 늘린다.
- 원 선율과 마디별 화성을 저장한 뒤 musicomp의 given 화성, retrieval 피아노, lyrical, grade 8로 같은 곡을 편곡한다. 피아노 독주, 기타 독주(오선·TAB), 25현 가야금, 바이올린·피아노 2중주, 첼로를 더한 3중주, 비올라를 더한 4중주가 있다. 해당 곡을 첫 편곡할 때 엔진을 한 번 실행하고 이후 편성은 저장된 XML을 사용한다. 편곡이 실패하면 원 선율을 보존한다.
- 로컬 영구 주소, 표본 음원 재생, MusicXML 다운로드, 브라우저 인쇄·PDF 저장을 제공한다. 가야금은 편곡기의 가야금 악보와 고토 대체 음색을 사용한다. 기타의 중복 TAB 보표는 재생 대상에서 뺀다.

## 노래방 통계의 적용 범위

`musigen/data/karaoke_gestures.json`은 이전 전수 조사 `statistics.json`(SHA-256 `1164ba9a13faef895cce5c3f36c58be3de9e41b6f2f7d79c29f399b8adcde7fa`)에서 얻은 집계다. `melody.interval_pattern_4`와 `melody.rhythm_4`의 `top_document_support`와 `top` 합집합에서 각 40개 패턴과 선율 지지 수만 보관한다. 서버가 이 가중치로 음정·리듬을 각각 묶음 단위로 고르고, 입력 조성 및 앞선 음역에 맞춘다. 전수 집계의 상위 패턴을 이용한 규칙 기반 생성이다. 발전은 입력 음형의 이조·끝음 연장·쉼·재현, 화성은 팝 진행 후보와 각 마디 선율음의 지속 시간·첫박을 사용한다. 사용자 청취 평가와 대규모 기출 선율 비교는 남아 있다.

## 구현과 재현

- `musigen/motif_workshop.py`의 `motif`, `compose`, `arrangements`가 생성·저장·편곡을 담당한다. `studio.py`의 기존 로컬 서버에 세 POST 경로와 저장 목록을 연결했다. 기존 작곡 요청 보관 기능을 함께 사용할 수 있다.
- `workshop.html/css/js`, `workshop_audio.js`가 입력·악보·연주 화면을 제공한다. Verovio와 musicomp 샘플은 기존 로컬 설치의 자산이다. 음원 출처는 화면 하단에 표시한다.
- `MUSICOMP_ROOT`를 musicomp 저장소로 설정하고 music21을 설치한 Python에서 `python -m musigen studio --out output/melody-studio --port 8808`을 실행한다. 이 출력의 `compositions`에 악보와 입력이 저장된다.
- [두 박에서 시작한 노래](http://127.0.0.1:8808/compose.html?piece=398b85410a434959b535de835f95b770&voice=melody)는 검수용 예시다. 첫 두 박 E♭4(반 박), 쉼(반 박), F4(한 박)를 입력했다. 1–2마디 완성 구간, 3–4마디의 응답, 8마디 종결을 들어본다.

## 검증

- 새 테스트 3개 통과. 원 입력의 음높이·음가·쉼을 MusicXML 재파싱으로 확인했다. 세 박자의 자동·이어쓰기와 완성 길이, 시드 재현, 이미 채워진 두 마디 거절을 확인했다. 별도 66개 설정 조합에서 16마디 총길이가 일치했다.
- 실제 8808에서 자동 생성, 부분 입력 이어쓰기, 작곡, 6개 편곡의 파트 수·XML 제목·악보 렌더링·샘플 요청, 고유 주소 다시 열기, 모바일 너비를 확인했다. 기존 MusicXML 선택 구간의 이동과 기타 인쇄용 PDF 파일 생성도 확인했다. 기존 작품 목록 47개를 대조했다. 사람의 청취 선호와 실제 악기 연주 적합성은 별도 검수 대상이다.
- 전체 테스트 286개 중 285개 통과. 기존 프레이즈 검증 1개는 현재 외부 musicomp의 분절 4구절과 기존 기대 6구절 차이로 계속 실패한다.
