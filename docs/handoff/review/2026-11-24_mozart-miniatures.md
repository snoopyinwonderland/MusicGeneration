# 모차르트풍 피아노 소품 세 곡 검수

- 요청에 따라 기존 선율 입력 없이 무작위 추출로 새 선율을 썼다. 각 곡은 16마디이며 두 마디 모티프를 작업실 입력기에 제공한다.
- [햇살 아래 미뉴에트](http://127.0.0.1:8808/compose.html?piece=a60d4bb31f095921bd9f29f30ab9f8ae) G장조 3/4, 27초, 시드 714832. [작은 극장의 메아리](http://127.0.0.1:8808/compose.html?piece=b0c10aac3bdc5a0bb1e65e640f8ef46c) D단조 4/4, 42초, 시드 368271. [정원을 도는 제비](http://127.0.0.1:8808/compose.html?piece=24d6017670a9559189546fa1f281ec4d) D장조 6/8, 22초, 시드 921457. 첫 주제와 13마디의 귀환을 비교할 수 있다.
- `scripts/mozart_miniatures.py`가 기존 musicomp의 DCML mozart-sonatas 적격 train 마디 중 같은 박자·마디 길이 597/434/341개에서 유음 음정의 빈도와 왼손 유형 빈도를 읽는다. 참고 데이터는 DCML Mozart Piano Sonatas, CC BY-NC-SA 4.0. 이번 참조는 비상업 실험이다. 리듬 후보·화성 설계와 반주 배치는 작성자가 정했다. 반주 유형을 가중 추출하고 구절의 중간과 끝에 화음 응답과 쉼을 배치했다.
- `musigen/workshop.js`가 등록된 피아노 완성본을 기본 악보로 열며 원 선율+화성 버튼으로 비교할 수 있다. 재현 명령은 `python -m scripts.mozart_miniatures output/melody-studio`이다. 기본 작곡 모델에 새 스타일을 적용하지 않았다.
- 각 MusicXML을 다시 읽어 한 파트 두 보표, 원 선율보와 오른손의 발음·음가·쉼, 총 길이를 확인했다. Edge에서 세 곡의 16마디 표시, 전곡 재생 시간과 피아노 샘플 로드를 확인했다. 모차르트 양식 유사도와 선호도는 청취 검수 전이다. Python 전체 회귀 294/295 통과. 기존 프레이즈 경계 테스트에서 4구간과 기대 6구간의 차이가 남았다.
