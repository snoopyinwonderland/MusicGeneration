# 가사 정서 단서 전수 통계 검수 요청

- `codex/karaoke-lyric-affect`에서 집계했다. 요구사항은 전체 노래방 원본의 가사와 선율 윤곽·음정·리듬 묶음·명시 화음 연결의 관계를 조사하는 것이다.
- `scripts/karaoke_lyric_associations.py`에서 기존 선율 검증 결과에 원본 가사 이벤트를 정렬한다. 여섯 범주의 어휘 단서, 동일 파일 대조, 동일 음표 수 대조와 묶음 빈도를 계산한다. `scripts/report_karaoke_lyric_associations.py`는 원문 없이 HTML을 만든다.
- [분모·제외와 주요 비교](../../KARAOKE_LYRIC_ASSOCIATIONS.md), [모든 특징 표](http://127.0.0.1:8808/karaoke-lyric-associations.html). 입력 파일 50,874개를 모두 계수했다. 재생성·청취 및 기본 작곡 동작 변경은 없다.
- MIDI가 단어 내부 음절 뒤에도 공백을 넣는 사례를 확인하고 한글 음절 사이 공백을 정규화한 뒤 전수 재집계했다. 관련 회귀 테스트를 추가했다. Python 회귀 결과 294/295 통과, 기존 프레이즈 분절 기대값 실패 한 건.
- 검수 시 무표지와 중립을 구별하고 HTML의 창 수 분모와 대응 파일 수 분모를 확인한다. 분류 정확도 및 생성 곡의 지각 정서는 평가 전이다. 원곡·가사 원문은 커밋하지 않았다.
