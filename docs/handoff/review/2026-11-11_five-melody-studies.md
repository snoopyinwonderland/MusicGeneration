## 무엇을 왜 바꿨는가

새로 관찰한 주선율 특징을 작곡자가 참고해 서로 다른 다섯 24마디 소품을 썼다. 자료를 이어 붙이거나 새 모델이 작곡한 결과로 표시하지 않는다. 기존 musicomp 반주 검색을 선택 사용해 같은 선율의 상세 화성 악보와 피아노 솔로를 만든다. 반복은 적절한 주제 재현으로 허용한다.

- `musigen/melody_collection.py`: `write`. 검증된 studio 전달 결과만 모아 두 악보의 재생·XML·PDF 링크와 들을 구간을 보여 준다. 작곡함 입력으로 연결하고 작성 예제/청취 검수 전을 표시한다.
- `musigen/print_score.py`: `display_copy`. Verovio 6.3의 증6화음 기준근음 노출·add9 중복 표기를 PDF용 표시 복사본에서만 정리한다. 원본 교환 MusicXML과 실제 음표는 보존한다.
- `tests/test_print_score.py`: 세 증6 종류·offset/staff·음 사건 불변, add9 표시 중복 제거.
- `README.md`, `docs/PLAN_STATUS_2026-11-11.md`: 최신 감상 모음·관찰 문서와 기존 P3/P4 상태를 구별해 연결.
- 악보, 작성 설계, 자료 관찰, 검사 JSON, PDF, 웹 페이지는 Git 제외 `output/`에 둔다. 곡별 예외를 생성 코드에 추가하지 않았다. 작품별 음표·voicing·악상은 작곡 데이터다.

작성 v001에서는 자료 반주 선택 후 3·7음 누락과 거친 voicing이 있었다. v004는 기존 선택 기능의 필수 3·7음/도입 베이스 조건을 사용하고, 연결과 종지는 직접 썼다. 작성 v003→v004에서는 사용자 후속 설명에 맞게 「바람과 세 걸음」17–18마디를 원형 재현으로 바꿨다. 반복 수를 낮추기 위한 변경은 하지 않았다.

최종 작성본 `output/five-studies/<곡ID>/v004`, 검증 후 첫 전달본 `output/melody-studio/requests/<요청ID>/results/v001`. 두 버전 체계는 다르며 이전 초안을 덮어쓰지 않았다. 예제 요청 출처는 `author_demo`이고 사용자 실제 선택을 만들지 않았다.

## 검증

- 10개 XML의 주선율·철자·박자·길이 일치, 122개 화성 구간의 필수 3·7음 포함. 자료 반주 70/120마디. 증6화음 지정 두 성부씩 총 4/4 실제 반음 해결, 해당 연결 쉼 0. 전곡 내성 자동 추적 인증은 아니다.
- 페달 구간 수는 순서대로 1/0/2/1/1. 원래 기본 생성은 불변이며 직접 after_rain 출력 SHA는 M1 검수서에 있다.
- 253개 회귀 검사 통과. PDF 10개 각 1페이지 렌더 및 시각 검수, 제목·실제 6/8 템포·증6 표시 확인. 원본 XML/PDF 표시 복사본의 역할 분리.
