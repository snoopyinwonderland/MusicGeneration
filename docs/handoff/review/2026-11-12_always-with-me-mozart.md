# 검수 요청 · Always With Me 전체 피아노 편곡

2026-11-12 · `codex/always-with-me-mozart` · 기준 `437758d`. [감상과 두 악보](http://127.0.0.1:8808/always-with-me-mozart.html)

## 편곡 범위

사용자가 기존 노래 전체를 모차르트 스타일로 편곡해 달라고 요청했다. 로컬 `Always With Me Melody.musicxml.xml`의 88마디를 처음부터 끝까지 사용했다. 보유 악보에 반복 기호가 없고 재현이 실제 마디로 적혀 있다. 선율보의 1–3마디와 4마디 처음 두 박은 쉬므로, 보유 `3. Always With Me, Piano Solo.musicxml.xml`의 전주 윗성부 15개 발음과 4마디로 이어진 붙임줄을 살렸다. 그 뒤 원 선율의 274개 발음은 철자·발음 시각·음가까지 유지했다. 원조 D장조, 3/4, ♩110과 88마디 구성을 유지했다. 작곡자 표기는 기무라 유미의 [공식 프로필](https://youmi-kimura.com/profile.html)에 따라 적고, 참조 악보 편곡자와 권리 표기는 XML에 보존했다.

## 전후 비교와 들어 볼 구간

선율보의 5–88마디 화음 자료 84개 중 68개는 원 기호와 베이스를 유지했다. 나머지 16개 마디는 11·12·19·23·27·29·36·46·53·64·65·73·82·83·85·87마디로, 딸림7화음·종지·전위와 마디 안의 화성 변화에 집중했다. 피아노 솔로의 왼손은 88마디 전체를 새로 배치했다. 총 96개 화성 구간의 실제 베이스, 구성음, 왼손 발음 시각과 음가가 상세 화성 JSON에 있다.

- 5–20마디에서 첫 노래의 펼침화음, 응답의 지속 저음과 화음, 19–20마디 종지를 비교한다.
- 47–49마디는 원본 셋잇단음표 27개 기보 사건과 256분할 틱을 유지했다. 왼손 발음을 마디당 한 번으로 줄였다.
- 재현부 일부에 알베르티 음형을 두고 66–72마디에 스타카토를 쓴다. 82–84마디는 종지 6/4에서 딸림7화음과 으뜸화음으로 진행한다.

자료는 모차르트 소나타 3/4 적격 train 마디 606개에서 확인했다. K.545 2악장의 알베르티, K.332 1악장의 펼침화음과 완전종지, K.309 2악장의 짧은 화음 발음을 참고해 배치를 직접 작성했다. 참조 음형의 ID와 관찰 근거는 `result.json`에 있다. 자료를 읽은 범위는 선택한 비상업 참조이며 사용자 청취 검수는 별도다.

## 사용자 의견을 반영한 수정판

사용자가 알베르티 베이스에 치우치지 않고 16분음표로 빠른 상·하행을 넣어 완급을 조절해 달라고 했다. 초기판 `v001`의 알베르티 분류를 12구간에서 4구간으로 줄였다. `v002`의 17·58·59·62마디에 알베르티를 남겼다. 초기판 분류에는 펼침 순서를 달리한 33마디가 포함된다.

18·35·44·55·56·70·79마디에 16분음표 네 음을 한 박으로 묶었다. 두 겹 빔이 각 묶음의 네 음에 연결됐음을 XML에서 확인했다. 55–56마디에서는 오른손의 쉼 사이로 왼손이 오르내리고, 79마디에서는 선율의 상승과 왼손의 하강이 교차한다. 빠른 음형 앞뒤의 긴 음으로 대비를 만들었다. 두 판 사이 왼손 기보가 바뀐 곳은 18·32·34·35·44·55·56·60·61·63·70·79마디다. 오른손 기보와 96개 화성 구간의 시점·길이·기호는 일치하며 상세 화성 MusicXML도 바이트가 같다.

[수정 전 피아노 솔로](http://127.0.0.1:8808/listen/always_with_me_mozart/v001/piano_solo.html)와 [수정판 피아노 솔로](http://127.0.0.1:8808/listen/always_with_me_mozart/v002/piano_solo.html)에서 비교할 수 있다.

## 산출물과 검증

작업 루트는 `K:/MusicGeneration/melody-research`. 편곡과 발행 스크립트는 Git 제외 `output/always-with-me-mozart/arrange.py`, `publish.py`다. `v001`은 초기판이고 `v002`에 수정판 두 악보와 검증 결과를 두었다. 저장소 변경 파일은 이 검수 요청서다.

- 두 XML을 다시 읽어 두 손의 음높이·철자·시각·길이가 작성본과 일치함을 확인했다. 실제 지속음을 포함한 왼손 최대 벌림은 10반음이며, 페달은 없다. 피아노 솔로의 베이스와 왼손 최상음에서 관찰된 병행 완전음정은 각각 0이다.
- 자동 검사 오류 0개. 솔로 경고 6개는 원 선율의 강박 비화성음 미분류 5개와 21–38마디의 원 선율 특성 유사 경고 1개다. 상세 화성판의 블록 배치에서는 병행 경고 4개가 추가된다.
- 두 악보 PDF는 각 4쪽이고 수정판 8쪽을 모두 렌더링해 확인했다. 브라우저 피아노 샘플 재생, 보표 아래 로마자 전환, XML·PDF·WAV 다운로드를 확인했다. 내려받은 악보는 작성본과 일치하고, WAV는 22.05kHz 모노·146.054초·포화 샘플 0이다. 감상 자원 14개 HTTP 해시가 전달 파일과 일치한다. 전체 Python 테스트 266개 통과.
