# Uptown Girl 메인 테마로 쓴 작은 소나티나

2026-11-11, `codex/uptown-mozart-study`. [감상·두 악보·다운로드](http://127.0.0.1:8808/uptown-mozart.html).

사용자 요청: “모차르트 스타일 새 작곡 한 번 해 보죠. 모티프는 Uptown Girl의 메인 Motif입니다. 악보의 처음 전주 부분이 아니라 메인 Theme이 나오는 부분을 가져다 쓰세요.”

「도시의 인사, 작은 소나티나」는 E장조, 4/4, ♩108, 32마디, 약 71초의 피아노 소품이다. 모차르트 소나타·변주 자료를 참고해 대화에서 직접 작성했다. 자동 스타일 모델이나 모차르트 전용 편곡 엔진의 완료를 뜻하지 않는다. 피아노 솔로와 같은 선율의 상세 화성 악보를 함께 제공한다.

## 모티프 선택

보유 `K:/Music Analysis/MusicXML/Uptown Girl.musicxml.xml`의 P1 / staff 1 / voice 1, **9마디 0박부터 10마디 끝까지**를 선택했다. 1–8마디의 순차적 4분음표 전주 뒤 9마디에 반복음 주제가 시작된다. 가사·구간명 주석이 없는 악보에서 작성자가 기보를 읽어 판단한 선택이며 사용자가 마디 번호를 지정했다고 기록하지 않는다.

두 마디는 8박, 9발음과 1박 쉼이다. 새 곡 1–2마디에 음높이·철자·음가·쉼을 그대로 보존했다. 별도 XML 순회와 기존 악보 파서의 추출을 대조했다. 원주제 Billy Joel, 참조 악보 편곡 Reflet des Nuages를 XML과 PDF·감상 페이지에 표시했다. 원 악보·음표·생성 결과는 Git 제외 output에만 둔다.

## 참고한 자료와 작성 판단

- 작곡가 검색: 기존 Mozart sonatas train 적격 2,572마디 / 14개 작품 묶음 중 같은 4/4의 434마디에서 다섯 사례를 조회했다. K309-1:143의 pulse, K311-1:57의 arpeggio, K333-1:141·K570-2:6의 mixed, K545-1:1의 alberti 후보를 확인했다. ID의 숫자는 라이브러리 마디 ID다. 검색은 첫 마디의 밀도·쉼·순차진행 비율에 따른 잠정 거리이며 스타일 품질 점수가 아니다.
- TAVERN 관찰을 다시 실행했다. K.265의 주제/제1변주에서 이웃음 왕복 0/14 → 10/49 연속 유음 세 음 창, K.25에서는 주제 발음점 27개 중 27개 시각 공유·24개 음고류 일치를 확인했다. 전체 관찰의 25개 후보 중 5개만 관찰 가능했으며, 이번 작성 근거로는 위 두 작품만 사용했다.
- 이를 참고해 반복음의 정체성을 남기고 18·26마디에 장식을 작성했다. 반주는 알베르티·펼침화음·지속음·화음 응답을 교대한다. **참고 악보의 반주 음표를 가져오거나 musicomp retrieval을 실행하지 않았다.** 기보·검사·피아노 재생은 기존 도구를 사용한다.
- 출처·해시는 `style-reference/references.json`, `variation-references.json`에 있다. 기존 DCML 파생 자료의 비상업 참조 범위와 TAVERN CC BY-SA 출처를 유지하며 새 모델 학습·전체 자료의 생성용 승격은 하지 않았다.

## 곡의 흐름

| 마디 | 작성 내용 |
|---|---|
| 1–8 | 원형 두 마디와 새 대답. 5마디는 다른 음높이의 반복음 응답. 4·8마디 후반에 양손 쉼 |
| 9–16 | B장조 구간. 반복음의 짧은 조각과 순차적 꼬리, 딸림 준비와 B장조 종결 |
| 17–24 | 짧은 장식·주고받기, 19마디 B5 정점 뒤 긴 음. E장조 귀환을 준비하며 24마디 후반 양손 쉼 |
| 25–32 | 원형 첫 마디를 모티프 조각으로 재현하고 두 번째 마디의 꼬리를 장식. 음역을 낮추고 E장조에서 종결 |

E장조–B장조–E장조의 밝은 중심을 유지한다. 단조 화음은 구절 안의 기능으로 사용한다. 소나타 형식 전체를 재현한 작품이라는 뜻은 아니다. 페달은 없고, 구간별 셈여림·헤어핀과 기존 선택 재생 균형(RH 1, LH .8, 동시 LH 음량 완화)을 사용한다.

## 확인한 것과 한계

- 두 악보 XML 재읽기 일치. 같은 주선율 134발음, 39개 화성 구간, 국소 조성은 1–8 E / 9–16 B / 17–32 E로 대조했다. 첫 모티프 보존과 원 악보 해시 불변 확인.
- 실제 지속음을 포함한 LH 최대 폭 10반음, 양손 교차 오류 없음. 39개 화성 구간 모두 왼손 구성음 생략 없음. 화성별 겹치는 발음의 합집합 검사이며 모든 구성음이 동시에 울린다는 뜻은 아니다.
- 쉼에서 비교를 끊는 외곽선 검사에서 LH 최저음·최고음 각각 병행 완전음정 0. 전체 내성 검증은 아니다.
- 솔로 오류 0·경고 6: 강박 비화성음 미분류 5개(6·17·18·28·29마디), 2박 양손 쉼을 넘긴 24→25마디 병행 8도 경고 1개. 화성 요약은 오류 0·경고 7이며 10→11마디 블록 화음의 병행 경고도 있다. 경고를 숨기지 않았다.
- 기존 프레이즈 분석 도구를 실행해 관찰을 감상 화면에 제공한다. 구절 분절의 정답이나 청취 품질 판정으로 사용하지 않는다.
- 전체 Python 테스트 266개 통과. PDF 두 개 각 1쪽을 렌더링하여 확인했다. 브라우저 피아노 샘플 재생·정지, Roman Numeral Analysis 전환, XML/PDF/WAV 다운로드를 확인했다. 내려받은 XML/PDF가 원본과 일치한다.
- WAV 44.1kHz 모노, 70.971초, PCM16 최댓값 9,954, 포화 샘플 0. 이 수치는 청취 평가를 대신하지 않는다.

작업 루트는 `K:/MusicGeneration/melody-research`, 제작 스크립트는 `output/uptown-mozart/author.py`, 출력·출처·검증은 같은 폴더에 있다. 작성 v004 / 감상 전달 v002가 최종이다. v001–v003은 연결 및 국소 조성 지정 검토용 중간 결과다. 기존 입력 화면이 E major를 받지 않아 작곡함 등록 대신 별도 정적 감상 URL로 제공했다. 곡을 C장조 요청으로 잘못 등록하거나 입력 화면을 이번에 확장하지 않았다.

청취할 핵심은 첫 두 마디의 주제 인식, 9–16마디의 연결, 17–24마디의 장식과 여백, 25마디의 귀환이다. 작곡가 스타일 재현의 설득력은 아직 사용자 청취 평가 전이다.
