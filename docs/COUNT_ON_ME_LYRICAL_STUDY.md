# Count On Me 주제 발전 — 네 곁으로 돌아오는 길

2026-11-11, `codex/count-on-me-lyrical`. 사용자 요청으로 보유 악보의 첫 노래 구절을 가져와 32마디 피아노 곡을 작성했다. [감상·두 악보·XML/PDF](http://127.0.0.1:8808/count-on-me.html). 기술 검증을 마친 청취 전 초안이며 기본 생성 동작은 바꾸지 않았다.

## 요청과 작성자의 선택

> Count On Me 주선율을 이용해서 한 곡 만들어 보죠. 반음계를 이용하고 편곡 엔진을 쓴다면 lyrical 스타일을 고릅니다.

- 원본: `K:\Music Analysis\MusicXML\Count on Me Melody.musicxml.xml`의 P1 / staff 1 / voice 1, 4마디 처음부터 7마디 끝까지. 곡은 사용자가 지정했고 이 구간은 작성자가 선택했다.
- 원주제 크레딧: Bruno Mars 외. 참조 악보의 표기: Reflet des Nuages 편곡 / MUSICALIBRA Corporation. 가사는 사용하지 않았다.
- 시작·끝 쉼과 6→7마디 붙임줄을 포함한 16박, 15발음을 첫 네 마디에 보존했다. musicomp 재읽기와 별도 XML 순회 결과를 대조했다.
- 작성자의 제안: 「네 곁으로 돌아오는 길」, C장조, 4/4, ♩84, 32마디, 약 91초, 6급. 기존 작품의 주제 발전이며 완전한 신규 원주제라고 표시하지 않는다.

## 음악과 편곡 범위

| 구간 | 작성 의도 |
|---|---|
| 1–4 | 원본 첫 노래 구절과 그 호흡을 보존 |
| 5–8 | 반음 하행과 Fmaj7–Fm6 차용화음, 8마디 후반 양손 쉼 |
| 9–16 | 반음 보조음, B7–Em6의 국소 딸림 연결, 감7화음으로 이어지는 발전 |
| 17–24 | 19마디의 16분음표 움직임과 최고음 뒤 긴 음·여백, 24마디 첫 박 이후 양손 쉼 |
| 25–28 | 짧은 세포를 축약·반음 변형해 재현하고 후속 선율을 바꿈 |
| 29–32 | ii–V와 차용 화음의 색을 거쳐 C6로 종결. 페달은 32마디 한 곳 |

주선율과 화성은 대화에서 작성했다. 기존 `musicomp.stages.build_stages`를 `piano_mode='retrieval'`, `style_plan=[{'from_bar': 1, 'style': 'lyrical'}]`, `fills=False`, `pacing=True`, `grade=6`, `piano_only=True`, `seed=0`으로 호출했다. 단순한 계획 이름이 아니라 실제 실현 엔진에 lyrical을 전달했다. 32마디에 12곡의 반주 자료를 선택했다. 원곡의 편곡은 검색에서 제외했다. 실행의 제외 목록에는 문자열 검색에 함께 걸린 `Take Me Home, Country Roads`도 포함되며 실제 목록을 기록했다.

엔진 오른손은 채택하지 않고 작성한 주선율을 보존했다. 따라서 왼손만 분리했을 때 빠진 화음 구성음을 보완했다. 전체 38개 음표 수정 기록에는 26마디의 내성 보완도 포함된다. 8·24마디의 쉼과 32마디 종결은 별도로 작성했다. 최종 왼손 117개 음 사건 중 80개는 엔진 결과와 음·시각·길이·성부가 정확히 같다. 나머지는 수정 기록으로 구별한다. 음악을 모델에 새로 학습시킨 작업은 아니다.

## 두 악보의 차이

- **멜로디 + 상세 화성**: 39개 화성 구간의 전체 구성음·베이스·전위·국소 조성·의도를 남긴 요약 악보와 JSON.
- **피아노 솔로**: 같은 주선율과 실제 lyrical 반주를 바탕으로 다듬은 연주 악보. 24마디 후반 G7 구간은 의도한 양손 쉼으로 소리 내지 않는다. 따라서 실제 솔로에서 울리는 38개 화성 구간에는 전체 구성음이 있지만, 요약 악보의 39개를 모두 연주하는 것은 아니다. 구성음 집계는 구간 내 누적 음이며 모든 발음에서 동시에 완전 화음을 친다는 뜻은 아니다.

Roman Numeral Analysis와 Chord Symbols 전환은 기존 표시 기능이다. 현재 표시는 조성에 대한 기호이며 모든 세컨더리 기능을 정확히 이름 붙이는 분석기는 아니다. 예를 들어 B7–Em6를 작성자는 국소 딸림 연결로 설계했지만 화면은 VII⁷–iii(add6)로 표시한다. 전조 검증 완료로 주장하지 않는다.

## 확인 결과와 한계

- 전체 테스트 262개 통과. 두 XML의 121개 주선율 음·음가·철자·성부 재읽기 일치. 요약 악보의 39개 화음 시점·구성음·베이스 일치.
- 실제 지속음을 포함한 왼손 동시음 폭이 한 옥타브 이내다. 두 악보 모두 연주 불가 오류 0.
- 솔로 경고 6개: 수기로 쓴 재현을 input 변형 연산으로 추적하지 못한 경고 1개, 강박 비화성음 해결 미분류 5개. 요약 악보는 여기에 외성 병행 경고 3개가 더 있다. 경고를 숨기거나 검사 기준을 바꾸지 않았다.
- 선택 관찰에서 솔로의 주선율 대 왼손 최저음·최고음 윤곽 병행 완전음정 사건은 각각 0개. 전체 내성 대위법이나 음악적 품질을 인증하는 결과는 아니다.
- 실제 주선율 최장 음은 4박, 최장 쉼은 3.5박이며 16분음표도 포함한다. 같은 호흡을 매 마디 강제하지 않았다.
- PDF 두 개, 각 1쪽의 모든 페이지 시각 확인. 원주제와 발전·편곡 크레딧을 표기했다.
- 브라우저에서 피아노 샘플 재생·정지, 화성 표기 양방향 전환, 두 악보의 XML/PDF 다운로드 확인. HTTP 자원 20개 대조. PDF 다운로드는 바이트 일치, XML은 CRLF→LF 정규화 외 텍스트·XML 트리 일치.
- 원본 파일과 기본 예제 XML의 해시가 유지됐다. 소스·출력 악보·반주 데이터는 Git에 포함하지 않는다. 청취 승인은 아직 없다.
